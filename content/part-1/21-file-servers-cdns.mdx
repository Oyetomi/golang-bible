## Serving Files

*Stop 1 of 4.*

### Step 1: three handlers, one engine

<Define term="http.FileServer / http.ServeContent">
**`http.FileServer`** (or `http.FileServerFS` for an `fs.FS`, Go 1.22) serves a whole directory tree. **`http.ServeFile`** serves one file by path. **`http.ServeContent`** serves any `io.ReadSeeker`, such as bytes you generated. All three share one engine that sets `Content-Type`, `Last-Modified` and `Accept-Ranges`, answers conditional requests with `304`, and answers byte-range requests with `206`.
</Define>

```go
// Serve ./static under the /assets/ URL prefix.
mux.Handle("GET /assets/", http.StripPrefix("/assets/", http.FileServer(http.Dir("./static"))))
```

`http.Dir("./static")` presents the directory as a filesystem. `http.StripPrefix` removes `/assets/` from the URL first, so `/assets/app.js` becomes `app.js` and is looked up as `./static/app.js`; without it the server would look for `./static/assets/app.js`.

| Use | When |
|---|---|
| `http.FileServer(http.Dir(dir))` / `http.FileServerFS(fsys)` | A tree of static files |
| `http.ServeFile(w, r, path)` / `http.ServeFileFS(w, r, fsys, name)` | One known file |
| `http.ServeContent(w, r, name, modtime, readSeeker)` | Data you already have: a generated CSV, a PDF from object storage |

For generated content, pass `time.Time{}` as the modification time. `ServeContent` then omits `Last-Modified` rather than claiming "modified just now" on every request, which would defeat caching.

### Step 2: resumable downloads

<Define term="Range request (206 Partial Content)">
A **range request** is a GET with a header like `Range: bytes=1000-` asking for part of a file. The server answers **`206 Partial Content`** with just that part and a `Content-Range` header saying which bytes they are. It's how interrupted downloads resume and how video players jump to the middle.
</Define>

```go
package main

import (
	"bytes"
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
	"strings"
	"time"
)

// A pretend 60-byte "PDF". ServeContent needs an io.ReadSeeker so it can
// jump to any offset a Range header asks for.
var pdf = []byte(strings.Repeat("0123456789", 6))

func statement(w http.ResponseWriter, r *http.Request) {
	modified := time.Date(2026, 9, 1, 0, 0, 0, 0, time.UTC)
	http.ServeContent(w, r, "Q3-statement.pdf", modified, bytes.NewReader(pdf))
}

func main() {
	srv := httptest.NewServer(http.HandlerFunc(statement))
	defer srv.Close()

	// First attempt: the connection drops after 25 bytes.
	resp, _ := http.Get(srv.URL)
	got, _ := io.ReadAll(io.LimitReader(resp.Body, 25))
	resp.Body.Close()
	fmt.Printf("attempt 1: %s, Accept-Ranges=%s, kept %d of %s bytes\n",
		resp.Status, resp.Header.Get("Accept-Ranges"), len(got), resp.Header.Get("Content-Length"))

	// Resume: ask only for what's missing.
	req, _ := http.NewRequest("GET", srv.URL, nil)
	req.Header.Set("Range", fmt.Sprintf("bytes=%d-", len(got)))
	resp, _ = http.DefaultClient.Do(req)
	rest, _ := io.ReadAll(resp.Body)
	resp.Body.Close()
	fmt.Printf("attempt 2: %s, Content-Range=%s, got %d bytes\n",
		resp.Status, resp.Header.Get("Content-Range"), len(rest))

	fmt.Println("reassembled correctly:", bytes.Equal(append(got, rest...), pdf))
}
```

</GoPlayground>

### Step 3: content types

`ServeContent` and friends choose `Content-Type` from the file extension (`mime.TypeByExtension`), and if that's unknown, by sniffing the first 512 bytes (`http.DetectContentType`). Set it yourself only when you know better. And send `X-Content-Type-Options: nosniff` (ch19's security headers), so a browser never decides that a user-uploaded "image" is really HTML and runs its script.

### Step 4: don't leak files

<ConceptGrid cols={3}>
  <ConceptCard label="Directory listings">`http.FileServer` lists any directory without an `index.html`. Measured: a request for `/css/` returned an HTML page linking `app.9f3a1.css`. Serve only known files (Stop 3 shows how) or put an index in every directory.</ConceptCard>
  <ConceptCard label="Path traversal">`http.FileServer` cleans paths and rejects `..`, so `/../../etc/passwd` can't escape the root. The danger is your own code: `os.Open(dir + r.URL.Query().Get("file"))` is a hole.</ConceptCard>
  <ConceptCard label="os.Root (Go 1.24)">When you must open user-named files, `os.OpenRoot(dir)` returns a handle whose `Open` refuses anything outside `dir`, including via `..` or symlinks. Its `FS()` method gives an `fs.FS` you can serve.</ConceptCard>
  <Gotcha>Serve a dedicated public directory, never your project root: one stray `.env` or `.git` inside it and anyone can download it.</Gotcha>
</ConceptGrid>

## Caching Headers

*Stop 2 of 4.*

### Step 1: two questions every cache asks

Every browser and CDN holding a copy of a file needs two answers from you:

1. **How long may I use my copy without asking?** That's `Cache-Control`.
2. **Once that's over, has it changed?** That's a **validator**: `ETag` or `Last-Modified`.

<Define term="Cache-Control / ETag / conditional GET (304)">
**`Cache-Control`** tells caches what they may do: `max-age=N` (use for N seconds without asking), `no-cache` (store it, but check before every use), `no-store` (keep nothing), `public`/`private` (may a shared cache such as a CDN keep it?). **`ETag`** is a version identifier you choose, often a content hash; **`Last-Modified`** is a timestamp. A cache revalidates by sending `If-None-Match: <etag>` or `If-Modified-Since: <time>`, and if nothing changed the server answers **`304 Not Modified`** with headers only.
</Define>

That combination is the whole pattern:

| File | `Cache-Control` | Why |
|---|---|---|
| Fingerprinted asset (`app.9f3a1.js`) | `public, max-age=31536000, immutable` | Its content can never change at this URL, because a change means a new name |
| HTML (`index.html`) | `no-cache` | Must be checked every time, so a deploy reaches users at once |
| A signed-in user's statement | `private, no-store` | Never in a shared cache; nothing kept afterwards |

`no-cache` is badly named: it means "cache, but revalidate", not "don't cache". The one that means "don't keep it" is `no-store`.

### Step 2: validators, and who sets them

For files on disk, `http.FileServer` sends `Last-Modified` from the file's modification time and answers `If-Modified-Since` with 304 by itself. It does **not** make up an `ETag`; if you want one (content hashes are more reliable than timestamps across servers and deploys), set the header yourself before the file server runs, and it will honour `If-None-Match` against it.

### Step 3: the policy in one middleware

The policy depends on whether a URL is fingerprinted, so that test has to be right. The first version of this chapter used this:

```go
// BROKEN: path[len(path)-3:] is three characters; ".html" is five.
// They're never equal, so EVERY path, index.html included, counts as fingerprinted.
func isFingerprinted(path string) bool {
	return len(path) > 4 && path[len(path)-3:] != ".html"
}
```

That bug sends `index.html` out with `max-age=31536000, immutable`, so every browser that loads the page keeps the old HTML for a year and never sees another deploy. It's the worst possible caching bug, and it hides in a length mismatch. Match the fingerprint itself instead:

```go
// A fingerprint is a dot, 5+ hex characters, a dot, then an extension: app.9f3a1.js
var fingerprinted = regexp.MustCompile(`\.[0-9a-f]{5,}\.[a-z0-9]+$`)

func cacheControl(next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		if fingerprinted.MatchString(r.URL.Path) {
			w.Header().Set("Cache-Control", "public, max-age=31536000, immutable")
		} else {
			w.Header().Set("Cache-Control", "no-cache")
		}
		next.ServeHTTP(w, r)
	})
}
```

The lab at the end has you fix exactly the broken version.

**Recap.** `Cache-Control` says how long a copy may be used; `ETag`/`Last-Modified` let it be checked cheaply. Fingerprinted assets: immutable for a year. HTML: `no-cache`. Private data: `private, no-store`. Test the fingerprint check, because getting it wrong freezes your HTML.

## go:embed & io/fs

*Stop 3 of 4.*

### Step 1: files inside the binary

<ELI5
  concept="go:embed"
  analogy="Packing the photographs inside the album, rather than posting them separately."
  role="reader"
>

A web server needs its HTML, CSS and images. If it reads them from disk, deployment becomes two jobs: ship the binary *and* put the files beside it, at the path it expects, on every machine.

`go:embed` puts them **inside the binary** when you compile. Deployment is one file again, with no path that can be wrong and no file that can go missing. The catch: they're frozen at build time. Editing a file on the server changes nothing; the copy that's served is the one compiled in.

</ELI5>

<Define term="//go:embed / embed.FS">
**`//go:embed`** (Go 1.16) is a directive comment placed directly above a package-level variable. At build time the compiler copies the named files into the binary and fills the variable: a `string` or `[]byte` for one file, or an **`embed.FS`** for many. `embed.FS` is a read-only filesystem that implements `io/fs.FS`.
</Define>

```go
import "embed"

//go:embed templates/welcome.html
var welcomeHTML string // one file, as text

//go:embed static/logo.png
var logoPNG []byte // one file, as bytes

//go:embed static
var staticFiles embed.FS // a whole directory tree
```

The rules the compiler enforces:

- Paths are relative to the package's directory and can't reach outside it (`..` is refused).
- Patterns use `path.Match` syntax, which has **no recursive `**`**: `static/**/*.css` matches exactly one directory level, and failed with `no matching files found` when the CSS was two levels deep. To embed a whole tree, name the directory.
- When a *directory* is embedded, files whose names start with `.` or `_` are skipped: a stray `static/.env` was not included. Prefix `all:` (`//go:embed all:static`) to include them, and think twice before you do.

### Step 2: one interface for disk, binary and tests

`embed.FS` satisfies `io/fs.FS`, a one-method interface:

```go
type FS interface {
	Open(name string) (fs.File, error)
}
```

So do `os.DirFS(dir)`, `os.Root.FS()` and `testing/fstest.MapFS` (an in-memory filesystem for tests). Code written against `fs.FS` (`fs.ReadFile`, `fs.WalkDir`, `template.ParseFS`, `http.FileServerFS`) works with any of them. A common setup: read from disk in development so edits show on refresh, embed for release, same code:

```go noverify
var assets fs.FS = os.DirFS("static") // development

func init() {
	if !devMode {
		sub, err := fs.Sub(embeddedStatic, "static") // strip the "static/" prefix
		if err != nil {
			panic(err)
		}
		assets = sub
	}
}
```

`fs.Sub` matters: embedding `static` stores files as `static/app.js`, and without it a request for `/app.js` wouldn't find anything.

### Step 3: the trap: embedded files have no modification time

The first version of this chapter said embedded files carry the build time as their modification time. They don't: every file in an `embed.FS` reports a **zero** time. Measured on Go 1.27, `fs.Stat` on an embedded file returned `ModTime().IsZero() == true`, and `http.FileServerFS` then sent **no** `Last-Modified` and no `ETag`.

No validator means no `304`, ever: every revalidation of `index.html` re-downloads it in full. The fix is to compute an `ETag` per file once, at startup, and set it before the file server runs. This program does that, and also applies Stop 2's cache policy and refuses to list directories. `fstest.MapFS` stands in for `embed.FS` here (its files also have zero times), because the sandbox can't embed your files:

<GoPlayground>

```go
package main

import (
	"crypto/sha256"
	"encoding/hex"
	"fmt"
	"io/fs"
	"net/http"
	"net/http/httptest"
	"regexp"
	"testing/fstest"
)

// fstest.MapFS behaves like embed.FS here: files with no modification time.
var assets = fstest.MapFS{
	"index.html":        {Data: []byte(`<script src="/app.9f3a1c.js"></script>`)},
	"app.9f3a1c.js":     {Data: []byte(`console.log("meridian")`)},
	"css/app.4ab2f.css": {Data: []byte(`body{margin:0}`)},
}

// fingerprinted matches names like app.9f3a1c.js: a dot, 5+ hex chars, a dot, an extension.
var fingerprinted = regexp.MustCompile(`\.[0-9a-f]{5,}\.[a-z0-9]+$`)

// staticHandler serves fsys with ETags computed once at startup, and a
// cache policy that depends on whether the URL is fingerprinted.
func staticHandler(fsys fs.FS) (http.Handler, error) {
	etags := map[string]string{}
	err := fs.WalkDir(fsys, ".", func(p string, d fs.DirEntry, err error) error {
		if err != nil || d.IsDir() {
			return err
		}
		b, err := fs.ReadFile(fsys, p)
		if err != nil {
			return err
		}
		sum := sha256.Sum256(b)
		etags["/"+p] = `"` + hex.EncodeToString(sum[:8]) + `"`
		return nil
	})
	if err != nil {
		return nil, err
	}
	etags["/"] = etags["/index.html"] // FileServer serves index.html for "/"

	files := http.FileServerFS(fsys)
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		tag, ok := etags[r.URL.Path]
		if !ok {
			http.NotFound(w, r) // no directory listings, no guessing
			return
		}
		w.Header().Set("ETag", tag) // FileServer honours If-None-Match against it
		if fingerprinted.MatchString(r.URL.Path) {
			w.Header().Set("Cache-Control", "public, max-age=31536000, immutable")
		} else {
			w.Header().Set("Cache-Control", "no-cache") // HTML: always revalidate
		}
		files.ServeHTTP(w, r)
```

<UnderTheHood title="Where embedded files live">

The build tool records the embedded files in the binary's read-only data, with a sorted index of names, so `Open` is a lookup in memory with no system call. That's why reading an embedded file can't fail with "file not found" in production, and why it adds its size to the binary. It's also why modification times aren't kept: builds are reproducible, and the same source must produce the same binary whenever it's built.

</UnderTheHood>

### Step 1: a copy near every user

<Define term="CDN / edge caching">
A **CDN** (content delivery network) runs cache servers, **edges**, in many cities. Users are routed to the nearest edge. On a **miss**, the edge fetches the file from your server (the **origin**) and keeps a copy for as long as `Cache-Control` allows; on a **hit**, it answers from its copy without contacting you.
</Define>

### Step 2: never invalidate, rename

<Define term="Fingerprinted asset URL">
A **fingerprinted URL** puts a hash of the file's contents in its name: `app.js` becomes `app.9f3a1.js`. Change the file and the name changes, so caches treat it as a new file. The old URL stays cached, harmlessly, until it expires.
</Define>

Without fingerprints, a deploy that changes `/static/app.js` leaves edges around the world serving the old copy until their `max-age` runs out, and users get new HTML with old JavaScript. You can call the CDN's purge API, but purges take time to spread, cost money, and are easy to forget. Fingerprints make them unnecessary.

Frontend build tools (Vite, esbuild, webpack) produce fingerprinted names plus a **manifest** mapping `app.js` to `app.9f3a1.js`. Your templates look names up in it:

```go
// Written by the frontend build; embedded alongside the assets.
var manifest = map[string]string{
	"app.js":     "app.9f3a1.js",
	"styles.css": "styles.4ab2f.css",
}

func assetURL(name string) string {
	if hashed, ok := manifest[name]; ok {
		return "/static/" + hashed
	}
	return "/static/" + name
}
```

Register `assetURL` in your template `FuncMap` and write `<script src="{{assetURL "app.js"}}">`.

### Step 3: private files through a CDN: signed URLs

Quarterly statements are per-user PDFs. They must never sit in a shared cache as a public URL, yet serving them straight from the origin loses the CDN's speed. A **signed URL** is a link that carries its own permission: an expiry time and an HMAC over the path and that expiry. Change either and the signature no longer matches.

```go
package main

import (
	"crypto/hmac"
	"crypto/sha256"
	"encoding/hex"
	"fmt"
	"strconv"
	"time"
)

var signingKey = []byte("load-me-from-the-secret-store")

func signature(path, exp string) string {
	mac := hmac.New(sha256.New, signingKey)
	mac.Write([]byte(path + "\n" + exp)) // a separator no path can contain
	return hex.EncodeToString(mac.Sum(nil))
}

func signedURL(path string, ttl time.Duration) (url, exp, sig string) {
	exp = strconv.FormatInt(time.Now().Add(ttl).Unix(), 10)
	sig = signature(path, exp)
	return "https://files.meridian.example" + path + "?exp=" + exp + "&sig=" + sig, exp, sig
}

func verify(path, exp, sig string) error {
	unix, err := strconv.ParseInt(exp, 10, 64)
	if err != nil {
		return fmt.Errorf("malformed expiry")
	}
	if time.Now().Unix() > unix {
		return fmt.Errorf("link expired")
	}
	want, _ := hex.DecodeString(signature(path, exp))
	got, err := hex.DecodeString(sig)
	if err != nil || !hmac.Equal(want, got) {
		return fmt.Errorf("bad signature")
	}
	return nil
}

func main() {
	path := "/statements/acc-100/Q3-2026.pdf"
	url, exp, sig := signedURL(path, 15*time.Minute)
	fmt.Println("link:", url[:60]+"…")

	fmt.Println("fresh link:       ", verify(path, exp, sig))
	old := strconv.FormatInt(time.Now().Add(-time.Hour).Unix(), 10)
	fmt.Println("expired link:     ", verify(path, old, signature(path, old)))
	later := strconv.FormatInt(time.Now().Add(24*time.Hour).Unix(), 10)
	fmt.Println("expiry edited:    ", verify(path, later, sig))
}
```

</GoPlayground>

</CodeWalk>

The handler that serves the file checks the link, then sends `Cache-Control: private, no-store`, and opens the file through an `os.Root` so a signed path still can't escape the statements directory. Managed CDNs (CloudFront, Cloudflare, Fastly) have their own signed-URL or signed-cookie formats that the edge checks for you; the principle is the same.

  <ConceptCard label="Signed URLs">A path, an expiry and an HMAC. Time-limited access to private files without a session.</ConceptCard>
  <ConceptCard label="private / no-store">`private`: browsers may cache, shared caches may not. `no-store`: nobody keeps a copy.</ConceptCard>

<Exercise n={3} title="From 200 to 304" level="medium">

Serve a `[]byte` with `http.ServeContent` and a content-hash `ETag`. Request it twice with `httptest`, the second time sending the first response's `ETag` as `If-None-Match`, and print both status codes and the second body's length.

<Solution>

```go
package main

import (
	"bytes"
	"crypto/sha256"
	"encoding/hex"
	"fmt"
	"net/http"
	"net/http/httptest"
	"time"
)

var payload = []byte(`{"accounts":[{"id":"acc_001","balance_cents":10000}]}`)

func handler(w http.ResponseWriter, r *http.Request) {
	sum := sha256.Sum256(payload)
	w.Header().Set("ETag", `"`+hex.EncodeToString(sum[:8])+`"`)
	http.ServeContent(w, r, "accounts.json", time.Time{}, bytes.NewReader(payload))
}

func main() {
	first := httptest.NewRecorder()
	handler(first, httptest.NewRequest("GET", "/accounts.json", nil))
	fmt.Println("first:", first.Code, first.Header().Get("ETag"))

	req := httptest.NewRequest("GET", "/accounts.json", nil)
	req.Header.Set("If-None-Match", first.Header().Get("ETag"))
	second := httptest.NewRecorder()
	handler(second, req)
	fmt.Println("second:", second.Code, "body bytes:", second.Body.Len())
}
```

`ServeContent` never invents an ETag, but it compares `If-None-Match` against one you set, and on a match writes `304` without reading the body. The zero `time.Time{}` keeps it from adding a meaningless `Last-Modified`.

</Solution>

</Exercise>

<Exercise n={5} title="Signed URLs, parsed from the link" level="hard">

Write `SignedURL(secret []byte, path string, ttl time.Duration) string` and `Verify(secret []byte, rawURL string) error`, where `Verify` takes the whole link, parses out the path, `exp` and `sig`, and returns `ErrExpired`, `ErrBadSignature` or `ErrMalformed`. <Solution>

```go
package main

import (
	"crypto/hmac"
	"crypto/sha256"
	"encoding/hex"
	"errors"
	"fmt"
	"net/url"
	"strconv"
	"time"
)

var (
	ErrExpired      = errors.New("link expired")
	ErrBadSignature = errors.New("bad signature")
	ErrMalformed    = errors.New("malformed link")
)

func sig(secret []byte, path, exp string) []byte {
	mac := hmac.New(sha256.New, secret)
	mac.Write([]byte(path + "\n" + exp))
	return mac.Sum(nil)
}

func SignedURL(secret []byte, path string, ttl time.Duration) string {
	exp := strconv.FormatInt(time.Now().Add(ttl).Unix(), 10)
	q := url.Values{"exp": {exp}, "sig": {hex.EncodeToString(sig(secret, path, exp))}}
	return "https://files.meridian.example" + path + "?" + q.Encode()
}

func Verify(secret []byte, rawURL string) error {
	u, err := url.Parse(rawURL)
	if err != nil {
		return ErrMalformed
	}
	exp, s := u.Query().Get("exp"), u.Query().Get("sig")
	unix, err := strconv.ParseInt(exp, 10, 64)
	if err != nil || s == "" {
		return ErrMalformed
	}
	if time.Now().Unix() > unix {
		return ErrExpired
	}
	got, err := hex.DecodeString(s)
	if err != nil || !hmac.Equal(got, sig(secret, u.Path, exp)) {
		return ErrBadSignature
	}
	return nil
}

func main() {
	secret := []byte("super-secret-key")
	good := SignedURL(secret, "/statements/Q3.pdf", 15*time.Minute)
	expired := SignedURL(secret, "/statements/Q3.pdf", -time.Hour)
	u, _ := url.Parse(good)
	u.Path = "/statements/Q4.pdf" // same signature, different file
	cases := []struct{ name, link string }{
		{"fresh", good},
		{"expired", expired},
		{"other file", u.String()},
		{"garbage sig", "https://files.meridian.example/statements/Q3.pdf?exp=9999999999&sig=zz"},
	}
	for _, c := range cases {
		fmt.Printf("%-11s -> %v\n", c.name, Verify(secret, c.link))
	}
}
```

Verifying the path from the parsed link, rather than trusting a separate argument, means the signature covers exactly what will be served.
