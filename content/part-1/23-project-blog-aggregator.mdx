## Schema and Layout

*Stop 1 of 6.*

### Step 1: three concerns, kept apart

Gator does three different jobs: **storage** (Postgres), **transport** (HTTP), and **background work** (the scraper). Each lives in its own package, and only `main` sees all of them:

```text
gator/
├── cmd/gator/main.go        wires everything; the only file that knows every package
├── migrations/001_init.sql  the schema
└── internal/                importable only from inside this module
    ├── store/               all SQL lives here, behind plain Go methods
    ├── auth/                API-key middleware
    ├── api/                 HTTP handlers and routes
    ├── scraper/             the background feed fetcher
    └── cache/               Redis: each account's first page of posts
```

The arrows only point inward. `api` and `scraper` never import each other, and neither knows Redis or Postgres exist: each declares a small interface for what it needs, and `main` passes in the real thing. That's the ports-and-adapters idea from ch14 (Software Design & Architecture), and it's what makes Stop 6's tests possible.

### Step 2: the schema

`migrations/001_init.sql`

```sql
CREATE TABLE accounts (
    id           UUID        PRIMARY KEY DEFAULT gen_random_uuid(),
    created_at   TIMESTAMPTZ NOT NULL DEFAULT now(),
    name         TEXT        NOT NULL,
    api_key_hash TEXT        NOT NULL UNIQUE -- SHA-256 of the key; the key itself is never stored
);

CREATE TABLE feeds (
    id              UUID        PRIMARY KEY DEFAULT gen_random_uuid(),
    created_at      TIMESTAMPTZ NOT NULL DEFAULT now(),
    account_id      UUID        NOT NULL REFERENCES accounts(id) ON DELETE CASCADE,
    name            TEXT        NOT NULL,
    url             TEXT        NOT NULL,
    last_fetched_at TIMESTAMPTZ,
    UNIQUE (account_id, url)
);

CREATE TABLE posts (
    id           UUID        PRIMARY KEY DEFAULT gen_random_uuid(),
    created_at   TIMESTAMPTZ NOT NULL DEFAULT now(),
    feed_id      UUID        NOT NULL REFERENCES feeds(id) ON DELETE CASCADE,
    title        TEXT        NOT NULL,
    url          TEXT        NOT NULL,
    description  TEXT,
    published_at TIMESTAMPTZ NOT NULL,     -- the item's date, or the fetch time if it had none
    UNIQUE (feed_id, url)                  -- re-scraping a feed never duplicates a post
);

-- Keyset pagination walks posts newest first, per feed.
CREATE INDEX posts_feed_published_idx ON posts (feed_id, published_at DESC, id DESC);
```

Every constraint here is doing a job:

- `api_key_hash` stores a SHA-256 of the key, never the key (Stop 2).
- `UNIQUE (feed_id, url)` makes re-scraping safe: inserting a post that's already there does nothing (`ON CONFLICT DO NOTHING`), so the scraper can run as often as it likes.
- `published_at` is `NOT NULL`. The first version allowed NULL, never parsed the RSS dates, and so stored every post with no date. Postgres sorts NULLs **first** in a `DESC` order, and `published_at < $1` is never true for NULL, so the feed's order and pagination were both broken for every post. Now the scraper always supplies a date: the item's own, or the fetch time.
- The index matches the query that reads posts: by feed, newest first, with `id` as a tiebreaker (Stop 3).

In a larger service you'd generate the data-access code from SQL with **sqlc** (ch18). Gator writes it by hand in one small file, so every query is visible in the chapter.

```go noverify
package main

import (
	"context"
	"database/sql"
	"errors"
	"log/slog"
	"net/http"
	"os"
	"os/signal"
	"sync"
	"syscall"
	"time"

	_ "github.com/jackc/pgx/v5/stdlib"
	"github.com/redis/go-redis/v9"

	"gator/internal/api"
	"gator/internal/cache"
	"gator/internal/scraper"
	"gator/internal/store"
)

func main() {
	if err := run(); err != nil {
		slog.Error("gator stopped", "err", err)
		os.Exit(1)
	}
}

func run() error {
	ctx, stop := signal.NotifyContext(context.Background(), os.Interrupt, syscall.SIGTERM)
	defer stop()

	// Storage: one pool for the whole process (ch18).
	db, err := sql.Open("pgx", mustEnv("DATABASE_URL"))
	if err != nil {
		return err
	}
	defer db.Close()
	db.SetMaxOpenConns(20)
	db.SetMaxIdleConns(10)
	db.SetConnMaxIdleTime(5 * time.Minute)
	pingCtx, cancel := context.WithTimeout(ctx, 3*time.Second)
	defer cancel()
	if err := db.PingContext(pingCtx); err != nil {
		return err
	}
	pg := store.NewPostgres(db)

	// Cache: a Redis outage should make Gator slower, not broken. Short
	// timeouts and one retry keep a dead Redis from stalling every request.
	rdb := redis.NewClient(&redis.Options{
		Addr:         envOr("REDIS_ADDR", "localhost:6379"),
		DialTimeout:  250 * time.Millisecond,
		ReadTimeout:  250 * time.Millisecond,
		WriteTimeout: 250 * time.Millisecond,
		MaxRetries:   1,
	})
	defer rdb.Close()
	c := cache.NewRedis(rdb)

	// Background scraper.
	var wg sync.WaitGroup
	scr := scraper.New(pg, c, 5)
	wg.Go(func() { scr.Run(ctx, time.Minute) })

	// HTTP (ch19's hardened server).
	srv := &http.Server{
		Addr:              envOr("LISTEN_ADDR", ":8080"),
		Handler:           api.NewRouter(pg, c),
		ReadHeaderTimeout: 5 * time.Second,
		ReadTimeout:       10 * time.Second,
		WriteTimeout:      30 * time.Second,
		IdleTimeout:       120 * time.Second,
	}
	errc := make(chan error, 1)
	go func() {
		slog.Info("listening", "addr", srv.Addr)
		if err := srv.ListenAndServe(); !errors.Is(err, http.ErrServerClosed) {
			errc <- err
		}
	}()

	select {
	case err := <-errc:
		return err
	case <-ctx.Done():
	}
	slog.Info("shutting down")
	shutdownCtx, cancel2 := context.WithTimeout(context.Background(), 20*time.Second)
	defer cancel2()
	err = srv.Shutdown(shutdownCtx) // finish in-flight requests
	wg.Wait()                       // and the scrape in progress
	return err
}

func mustEnv(k string) string {
	v := os.Getenv(k)
	if v == "" {
		slog.Error("missing required environment variable", "name", k)
		os.Exit(1)
	}
	return v
}

func envOr(k, def string) string {
	if v := os.Getenv(k); v != "" {
		return v
	}
	return def
}
```

## Auth Middleware

*Stop 2 of 6.*

### Step 1: an API key you never store

The first version generated keys in SQL with `encode(sha256(random()::text::bytea), 'hex')` and stored them as-is. Two problems. Postgres's `random()` is not a cryptographic generator, so keys could be predictable. And storing the raw key means anyone who reads the table (a backup, a leaked replica, a curious admin) can log in as every user. The fix is ch20's rule for any bearer secret:

### Step 2: the middleware

`auth.Middleware` reads `Authorization: ApiKey <key>`, looks the account up, and either answers 401 (with a `WWW-Authenticate` header saying how to authenticate) or passes the request on with the account attached. A failure to *reach* the database is a 503, not a 401: "we couldn't check" is different from "you're not allowed".

`internal/auth/auth.go`

```go noverify
// Package auth resolves "Authorization: ApiKey <key>" into an account.
package auth

import (
	"context"
	"errors"
	"net/http"
	"strings"

	"gator/internal/store"
)

// Accounts is the one thing auth needs from storage.
type Accounts interface {
	AccountByAPIKey(ctx context.Context, key string) (store.Account, error)
}

type ctxKey struct{} // unexported: no other package can collide with it

// WithAccount returns ctx carrying acct. Tests use it to skip the header dance.
func WithAccount(ctx context.Context, acct store.Account) context.Context {
	return context.WithValue(ctx, ctxKey{}, acct)
}

// FromContext returns the authenticated account. ok is false outside Middleware.
func FromContext(ctx context.Context) (store.Account, bool) {
	a, ok := ctx.Value(ctxKey{}).(store.Account)
	return a, ok
}

// Middleware rejects requests without a valid API key with 401,
// and passes the rest on with the account in their context.
func Middleware(accounts Accounts, next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		scheme, key, found := strings.Cut(r.Header.Get("Authorization"), " ")
		if !found || scheme != "ApiKey" || key == "" {
			unauthorized(w, "missing API key")
			return
		}
		acct, err := accounts.AccountByAPIKey(r.Context(), key)
		if errors.Is(err, store.ErrNotFound) {
			unauthorized(w, "invalid API key")
			return
		}
		if err != nil {
			http.Error(w, "auth unavailable", http.StatusServiceUnavailable)
			return
		}
		next.ServeHTTP(w, r.WithContext(WithAccount(r.Context(), acct)))
	})
}

// unauthorized answers 401 and says how to authenticate, as HTTP requires.
func unauthorized(w http.ResponseWriter, msg string) {
	w.Header().Set("WWW-Authenticate", `ApiKey realm="gator"`)
	http.Error(w, msg, http.StatusUnauthorized)
}
```

`ctxKey` is an unexported, empty struct type. Context values are looked up by key *and type*, so no other package can read or overwrite this value, even by accident: it can't name the type. `WithAccount` exists so tests (and nothing else) can put an account on a context directly.

The same pattern, runnable without a database:

### Step 1: the handlers depend on interfaces

The first version's `NewRouter` took the concrete `*database.Queries` and `*cache.Cache`, and its tests then passed in stub types, which can't compile: a `*stubQueries` isn't a `*database.Queries`.
```go noverify
// Package api is Gator's HTTP layer.
package api

import (
	"context"
	"encoding/base64"
	"encoding/json"
	"errors"
	"net/http"
	"strconv"
	"strings"
	"time"

	"gator/internal/auth"
	"gator/internal/store"
)

// Store is everything the handlers need from storage. It's declared here, by
// the code that uses it, so tests can pass a small in-memory fake.
type Store interface {
	auth.Accounts
	CreateAccount(ctx context.Context, name string) (store.Account, string, error)
	AddFeed(ctx context.Context, accountID, name, url string) (store.Feed, error)
	FeedsForAccount(ctx context.Context, accountID string) ([]store.Feed, error)
	DeleteFeed(ctx context.Context, accountID, feedID string) error
	PostsForAccount(ctx context.Context, accountID string, after *store.Cursor, limit int) ([]store.Post, error)
}

// Cache holds each account's first page of posts.
type Cache interface {
	FirstPage(ctx context.Context, accountID string) ([]store.Post, bool)
	SetFirstPage(ctx context.Context, accountID string, posts []store.Post)
}

type Server struct {
	store Store
	cache Cache
}

const pageSize = 20

func NewRouter(s Store, c Cache) http.Handler {
	srv := &Server{store: s, cache: c}
	mux := http.NewServeMux()
	mux.HandleFunc("POST /v1/accounts", srv.createAccount) // the only public route

	authed := func(h http.HandlerFunc) http.Handler { return auth.Middleware(s, h) }
	mux.Handle("GET /v1/feeds", authed(srv.listFeeds))
	mux.Handle("POST /v1/feeds", authed(srv.addFeed))
	mux.Handle("DELETE /v1/feeds/{id}", authed(srv.deleteFeed))
	mux.Handle("GET /v1/posts", authed(srv.listPosts))
	return mux
}

func (s *Server) createAccount(w http.ResponseWriter, r *http.Request) {
	var req struct {
		Name string `json:"name"`
	}
	if !decode(w, r, &req) {
		return
	}
	if strings.TrimSpace(req.Name) == "" {
		writeError(w, http.StatusUnprocessableEntity, "name is required")
		return
	}
	acct, key, err := s.store.CreateAccount(r.Context(), req.Name)
	if err != nil {
		writeError(w, http.StatusInternalServerError, "could not create account")
		return
	}
	// The key is returned exactly once. Only its hash is stored.
	writeJSON(w, http.StatusCreated, map[string]string{"id": acct.ID, "name": acct.Name, "api_key": key})
}

func (s *Server) listFeeds(w http.ResponseWriter, r *http.Request) {
	acct, _ := auth.FromContext(r.Context())
	feeds, err := s.store.FeedsForAccount(r.Context(), acct.ID)
	if err != nil {
		writeError(w, http.StatusInternalServerError, "could not list feeds")
		return
	}
	writeJSON(w, http.StatusOK, map[string]any{"feeds": nonNil(feeds)})
}

func (s *Server) addFeed(w http.ResponseWriter, r *http.Request) {
	acct, _ := auth.FromContext(r.Context())
	var req struct {
		Name string `json:"name"`
		URL  string `json:"url"`
	}
	if !decode(w, r, &req) {
		return
	}
	if req.Name == "" || !(strings.HasPrefix(req.URL, "https://") || strings.HasPrefix(req.URL, "http://")) {
		writeError(w, http.StatusUnprocessableEntity, "name and an http(s) url are required")
		return
	}
	feed, err := s.store.AddFeed(r.Context(), acct.ID, req.Name, req.URL)
	if err != nil {
		writeError(w, http.StatusInternalServerError, "could not add feed")
		return
	}
	writeJSON(w, http.StatusCreated, feed)
}

func (s *Server) deleteFeed(w http.ResponseWriter, r *http.Request) {
	acct, _ := auth.FromContext(r.Context())
	err := s.store.DeleteFeed(r.Context(), acct.ID, r.PathValue("id"))
	switch {
	case errors.Is(err, store.ErrNotFound):
		writeError(w, http.StatusNotFound, "no such feed") // yours or not: same answer
	case err != nil:
		writeError(w, http.StatusInternalServerError, "could not delete feed")
	default:
		w.WriteHeader(http.StatusNoContent)
	}
}

func (s *Server) listPosts(w http.ResponseWriter, r *http.Request) {
	acct, _ := auth.FromContext(r.Context())

	var after *store.Cursor
	if raw := r.URL.Query().Get("after"); raw != "" {
		c, err := decodeCursor(raw)
		if err != nil {
			writeError(w, http.StatusBadRequest, "invalid cursor")
			return
		}
		after = &c
	}

	var posts []store.Post
	cached := false
	if after == nil { // only the first page is cached: it's what everyone loads
		posts, cached = s.cache.FirstPage(r.Context(), acct.ID)
	}
	if !cached {
		var err error
		posts, err = s.store.PostsForAccount(r.Context(), acct.ID, after, pageSize+1)
		if err != nil {
			writeError(w, http.StatusInternalServerError, "could not load posts")
			return
		}
		if after == nil {
			s.cache.SetFirstPage(r.Context(), acct.ID, posts)
		}
	}

	// We asked for one extra row: if it came back, there's another page.
	resp := struct {
		Posts      []store.Post `json:"posts"`
		NextCursor string       `json:"next_cursor,omitempty"`
	}{Posts: posts}
	if len(posts) > pageSize {
		resp.Posts = posts[:pageSize]
		last := resp.Posts[pageSize-1]
		resp.NextCursor = encodeCursor(store.Cursor{PublishedAt: last.PublishedAt, ID: last.ID})
	}
	writeJSON(w, http.StatusOK, resp)
}

// Cursors are opaque to clients: base64 of "unix-nanos|id".
func encodeCursor(c store.Cursor) string {
	return base64.RawURLEncoding.EncodeToString([]byte(strconv.FormatInt(c.PublishedAt.UnixNano(), 10) + "|" + c.ID))
}

func decodeCursor(s string) (store.Cursor, error) {
	b, err := base64.RawURLEncoding.DecodeString(s)
	if err != nil {
		return store.Cursor{}, err
	}
	nanos, id, ok := strings.Cut(string(b), "|")
	n, err := strconv.ParseInt(nanos, 10, 64)
	if !ok || err != nil || id == "" {
		return store.Cursor{}, errors.New("malformed cursor")
	}
	return store.Cursor{PublishedAt: time.Unix(0, n).UTC(), ID: id}, nil
}

func decode(w http.ResponseWriter, r *http.Request, v any) bool {
	r.Body = http.MaxBytesReader(w, r.Body, 1<<20)
	d := json.NewDecoder(r.Body)
	d.DisallowUnknownFields()
	if err := d.Decode(v); err != nil {
		writeError(w, http.StatusBadRequest, "invalid JSON body")
		return false
	}
	return true
}

func writeJSON(w http.ResponseWriter, status int, v any) {
	w.Header().Set("Content-Type", "application/json")
	w.WriteHeader(status)
	json.NewEncoder(w).Encode(v)
}

func writeError(w http.ResponseWriter, status int, msg string) {
	writeJSON(w, status, map[string]string{"error": msg})
}

	if s == nil {
		return []T{}
```

### Step 2: pagination that can't skip or repeat

The first version paginated on `published_at` alone: `WHERE published_at < $1`. Two posts published in the same second (common when a feed is scraped in one batch) straddling a page boundary: the second one is never shown, because it isn't *strictly* older than the cursor. The keyset from ch20 fixes it by making the order unique:

```sql
WHERE (p.published_at, p.id) < ($2, $3)
ORDER BY p.published_at DESC, p.id DESC
```

The row comparison `(a, b) < (x, y)` means "a < x, or a = x and b < y", exactly the order the `ORDER BY` walks. Stop 6's tests page through posts that share timestamps (in pairs in the handler test, in fives against real Postgres) and check that every post appears exactly once.

The cursor itself is just the last row's two values, encoded:

## Concurrent Feed Fetcher

*Stop 4 of 6.*

<ELI5
  concept="Fetching many feeds without becoming the problem"
  analogy="Knocking on a hundred doors: politely, a few at a time, and moving on if nobody answers."
  role="reader"
>

Fetching a hundred feeds one after another takes as long as all of them added together. Fetching them all at once fixes that and creates four new problems:

- **Unbounded goroutines.** A hundred is fine; a hundred thousand feeds is a hundred thousand sockets. Cap how many are in flight.
- **No timeout.** One dead server holds a goroutine and a connection forever. Every fetch needs a deadline.
- **Politeness.** Many feeds on one host means many simultaneous requests to one server. Real crawlers also limit per host.
- **Failure is normal.** At a hundred feeds, some fail on every run. The run must keep the good results and move on.

</ELI5>

```go noverify
	"context"

// Store is what the scraper needs from storage.
type Store interface {
	FeedsToFetch(ctx context.Context) ([]store.Feed, error)
	InsertPost(ctx context.Context, p store.Post) (bool, error)
	MarkFetched(ctx context.Context, feedID string) error
}

// Invalidator drops an account's cached first page.
type Invalidator interface {
	Invalidate(ctx context.Context, accountID string) error
}

type Scraper struct {
	store   Store
	cache   Invalidator
	client  *http.Client
	workers int
}

func New(s Store, c Invalidator, workers int) *Scraper {
	return &Scraper{
		store:   s,
		cache:   c,
		client:  &http.Client{Timeout: 15 * time.Second}, // never DefaultClient (ch16)
		workers: workers,
	}
}

// Run scrapes once immediately, then every interval, until ctx is cancelled.
// It returns only after the in-flight scrape has finished.
func (s *Scraper) Run(ctx context.Context, interval time.Duration) {
	ticker := time.NewTicker(interval)
	defer ticker.Stop()
	for {
		s.ScrapeOnce(ctx)
		select {
		case <-ctx.Done():
			return
		case <-ticker.C:
		}
	}
}

// ScrapeOnce fetches every feed with at most s.workers in flight, and
// waits for all of them. It returns how many new posts were stored.
func (s *Scraper) ScrapeOnce(ctx context.Context) int {
	feeds, err := s.store.FeedsToFetch(ctx)
	if err != nil {
		slog.Error("list feeds", "err", err)
		return 0
	}
	var (
		wg    sync.WaitGroup
		mu    sync.Mutex
		total int
	)
	sem := make(chan struct{}, s.workers) // a counting semaphore: s.workers slots
	for _, feed := range feeds {
		select {
		case sem <- struct{}{}: // take a slot (blocks while all are busy)
		case <-ctx.Done():
			wg.Wait()
			return total
		}
		wg.Go(func() {
			defer func() { <-sem }() // give the slot back
			n, err := s.scrapeFeed(ctx, feed)
			if err != nil {
				slog.Warn("scrape failed", "feed", feed.URL, "err", err) // one bad feed never stops the rest
				return
			}
			mu.Lock()
			total += n
			mu.Unlock()
		})
	}
	wg.Wait()
	return total
}

type rss struct {
	Items []struct {
		Title       string `xml:"title"`
		Link        string `xml:"link"`
		Description string `xml:"description"`
		PubDate     string `xml:"pubDate"`
	} `xml:"channel>item"`
}

// Feeds in the wild use several date formats.
var dateLayouts = []string{time.RFC1123Z, time.RFC1123, time.RFC822Z, time.RFC822, time.RFC3339}

func parseDate(s string, fallback time.Time) time.Time {
	s = strings.TrimSpace(s)
	for _, layout := range dateLayouts {
		if t, err := time.Parse(layout, s); err == nil {
			return t.UTC()
		}
	}
	return fallback // no usable date: use the time we fetched it
}

func (s *Scraper) scrapeFeed(ctx context.Context, feed store.Feed) (int, error) {
	req, err := http.NewRequestWithContext(ctx, http.MethodGet, feed.URL, nil)
	if err != nil {
		return 0, err
	}
	req.Header.Set("User-Agent", "gator/1.0 (+https://gator.example/bot)")
	resp, err := s.client.Do(req)
	if err != nil {
		return 0, err
	}
	defer resp.Body.Close()
	if resp.StatusCode != http.StatusOK {
		return 0, fmt.Errorf("status %d", resp.StatusCode)
	}

	var doc rss
	if err := xml.NewDecoder(io.LimitReader(resp.Body, 5<<20)).Decode(&doc); err != nil { // 5 MiB cap
		return 0, fmt.Errorf("parse: %w", err)
	}

	fetchedAt := time.Now().UTC()
	inserted := 0
	for _, it := range doc.Items {
		if it.Link == "" || it.Title == "" {
			continue
		}
		ok, err := s.store.InsertPost(ctx, store.Post{
			FeedID:      feed.ID,
			Title:       it.Title,
			URL:         it.Link,
			Description: it.Description,
			PublishedAt: parseDate(it.PubDate, fetchedAt),
		})
		if err != nil {
			return inserted, err
		}
		if ok {
			inserted++
		}
	}
	if inserted > 0 {
		if err := s.cache.Invalidate(ctx, feed.AccountID); err != nil {
			slog.Warn("cache invalidate", "account", feed.AccountID, "err", err) // the TTL is the backstop
		}
	}
	return inserted, s.store.MarkFetched(ctx, feed.ID)
}
```

### Step 1: cache exactly one thing

```go noverify
// Package cache holds each account's first page of posts in Redis.
package cache

import (
	"context"
	"encoding/json"
	"time"

	"github.com/redis/go-redis/v9"

	"gator/internal/store"
)

const firstPageTTL = 2 * time.Minute

type Redis struct{ rdb *redis.Client }

func NewRedis(rdb *redis.Client) *Redis { return &Redis{rdb: rdb} }

// Per-account keys: one user's page can never be served to another.
func key(accountID string) string { return "gator:posts:first:" + accountID }

func (c *Redis) FirstPage(ctx context.Context, accountID string) ([]store.Post, bool) {
	raw, err := c.rdb.Get(ctx, key(accountID)).Bytes()
	if err != nil {
		return nil, false // a miss, or Redis down: either way, go to the database
	}
	var posts []store.Post
	if json.Unmarshal(raw, &posts) != nil {
		return nil, false
	}
	return posts, true
}

func (c *Redis) SetFirstPage(ctx context.Context, accountID string, posts []store.Post) {
	if raw, err := json.Marshal(posts); err == nil {
		c.rdb.Set(ctx, key(accountID), raw, firstPageTTL) // best effort
	}
}

// Invalidate drops an account's cached page; the scraper calls it after new posts.
func (c *Redis) Invalidate(ctx context.Context, accountID string) error {
	return c.rdb.Del(ctx, key(accountID)).Err()
}
```

Three decisions worth noticing:

- **Per-account keys.** A single shared "latest posts" key would serve Ada's feed to Finn. The account ID is part of the key.
- **Best effort.** `SetFirstPage` ignores Redis errors and `FirstPage` treats any error as a miss. With Redis switched off in the end-to-end run, every request still worked; it just went to Postgres.
- **Invalidation by owner.** The first version kept a Redis set of "subscribers" per feed and never updated it when feeds were added or deleted. Here each feed has exactly one owner, so the scraper deletes `feed.AccountID`'s key directly: nothing extra to keep in sync.

<Callout kind="warn" title="Never cache authoritative data">

The first page is derived and reconstructable: stale by two minutes, it's a mild annoyance. Credentials, permissions and (in a fintech) balances are authoritative: stale, they're wrong. Those always go to the source of truth.

</Callout>

**Recap.** Cache the one expensive, repeated read (each user's first page) with a per-account key, a TTL, and deletion when new posts land. Treat Redis as optional: errors are misses.

```go noverify
// PostsForAccount mimics the SQL: newest first by (published_at, id), after the cursor.
func (f *fakeStore) PostsForAccount(_ context.Context, _ string, after *store.Cursor, limit int) ([]store.Post, error) {
	f.mu.Lock()
	f.postReads++
	f.mu.Unlock()
	sorted := slices.Clone(f.posts)
	slices.SortFunc(sorted, func(a, b store.Post) int {
		return cmp.Or(b.PublishedAt.Compare(a.PublishedAt), strings.Compare(b.ID, a.ID))
	})
	out := []store.Post{}
	for _, p := range sorted {
		if after != nil && !(p.PublishedAt.Before(after.PublishedAt) ||
			(p.PublishedAt.Equal(after.PublishedAt) && p.ID < after.ID)) {
			continue
		}
		if len(out) == limit {
			break
		}
		out = append(out, p)
	}
	return out, nil
}
```

<UnderTheHood title="What the race detector adds">

`go test -race` compiles every memory access with instrumentation (ThreadSanitizer) and reports two goroutines touching the same memory without synchronisation, with both stacks. It only sees races that actually happen during the run, which is why the scraper test runs twelve fetches through three workers and the fakes are guarded by mutexes: the test must exercise the concurrency for the detector to check it. Expect 2–20× slower tests and more memory; run it in CI on every change.

</UnderTheHood>

**Recap.** Fakes behind the package's own interfaces for fast tests, `httptest` for anything that speaks HTTP, `miniredis` for Redis, a real database for SQL, and `-race` on all of it.

<Exercise n={2} title="Normalise post URLs" level="medium">

`https://Example.com/post/?utm_source=rss` and `https://example.com/post` are the same post.
```go
package scraper

import (
	"net/url"
	"strings"
)

func normalizeURL(raw string) (string, error) {
	u, err := url.Parse(strings.TrimSpace(raw))
	if err != nil {
		return "", err
	}
	u.Scheme = strings.ToLower(u.Scheme)
	u.Host = strings.ToLower(u.Host)
	u.Fragment = ""
	if len(u.Path) > 1 {
		u.Path = strings.TrimRight(u.Path, "/")
	}
	q := u.Query()
	for k := range q {
		if strings.HasPrefix(k, "utm_") {
			q.Del(k)
		}
	}
	u.RawQuery = q.Encode() // also sorts the remaining parameters
	return u.String(), nil
}
```

When many of Ada's requests miss the cache at once (after an invalidation, say), each one runs the first-page query. Put a `golang.org/x/sync/singleflight.Group` on `Server` so concurrent first-page misses for the same account share one query, and prove it with a test that fires 20 requests at an empty cache and counts `postReads`.

<Solution>

```go
// Add to Server:  group singleflight.Group

func (s *Server) loadFirstPage(ctx context.Context, accountID string) ([]store.Post, error) {
	v, err, _ := s.group.Do(accountID, func() (any, error) { // key by account: never share across users
		posts, err := s.store.PostsForAccount(context.WithoutCancel(ctx), accountID, nil, pageSize+1)
		if err == nil {
			s.cache.SetFirstPage(ctx, accountID, posts)
		}
		return posts, err
	})
	if err != nil {
		return nil, err
	}
	return v.([]store.Post), nil
}
```

In `listPosts`, call `loadFirstPage` when `after == nil` and the cache missed. The test:

The bound is "at most 2", not "exactly 1": a request that arrives after the first query finished but before the cache write lands can legitimately start a second. Tests about concurrency should assert what's guaranteed, not what's typical.

<Exercise n={4} title="Rate-limit per host" level="hard">

Three workers are polite overall, but if eight of the twelve feeds live on `medium.com`, three simultaneous requests can hit one host. Add a per-host limit of one in-flight request: a `map[string]chan struct{}` (one single-slot semaphore per host), created lazily under a mutex. Extend the concurrency test so all feeds share one host and assert the peak is 1.

<Solution>

```go
type hostLimiter struct {
	mu    sync.Mutex
	slots map[string]chan struct{}
}

func (h *hostLimiter) acquire(ctx context.Context, host string) (release func(), err error) {
	h.mu.Lock()
	ch, ok := h.slots[host]
	if !ok {
		ch = make(chan struct{}, 1) // one request per host at a time
		h.slots[host] = ch
	}
	h.mu.Unlock()

	select {
	case ch <- struct{}{}:
		return func() { <-ch }, nil
	case <-ctx.Done():
		return nil, ctx.Err()
	}
}
```

Add `hosts *hostLimiter` to `Scraper` (initialised in `New` with an empty map). In `scrapeFeed`, parse `feed.URL`, then `release, err := s.hosts.acquire(ctx, u.Host)` before the request and `defer release()`. With every test feed on the same `httptest` host, the recorded peak drops to 1 while the three global workers stay available for other hosts. Real crawlers add a minimum delay between requests to one host and honour `Retry-After` and `robots.txt` too.

</Solution>

</Exercise>
