## The Default Client Is a Trap

*Stop 1 of 6.*

### Step 1: the three objects behind every call

When you write `http.Get(url)`, three pieces of `net/http` do the work. Learn their names now, because the whole chapter is about configuring them:

```text
your code ──► http.Client ──► http.Transport ──► TCP connection ──► server
              the policy       the connections
              (timeout,        (dialing, TLS,
               redirects,       the pool of open
               cookies)         connections)
```

- **`http.Client`** decides *how long* you're willing to wait, whether to follow redirects, and which cookies to send. It doesn't open sockets itself.
- **`http.Transport`** does the actual networking: it dials, performs the TLS handshake, and keeps finished connections open so the next request can reuse them.
- **`http.Request` / `http.Response`** are the messages. A response's `Body` is a stream still attached to the connection, which is why you must close it (Stop 3).

### Step 2: `http.Get` uses a client with no timeout

`http.Get` is shorthand for `http.DefaultClient.Get`. `DefaultClient` is a package-level variable declared as `var DefaultClient = &Client{}`: a `Client` with every field left at its zero value. `Timeout` is a `time.Duration`, and its zero value, `0`, means **no limit at all**. Don't take my word for it:

```go
package main

import (
	"fmt"
	"net/http"
)

func main() {
	fmt.Println("DefaultClient.Timeout:", http.DefaultClient.Timeout)
	fmt.Println("means no limit:", http.DefaultClient.Timeout == 0)
}
```

</GoPlayground>


### Step 4: prove it with a server that never answers

This program builds a test server whose handler waits until the client hangs up. The client has a 300 ms timeout. (Swap `client.Get` for `http.Get` and the program never finishes; the sandbox eventually kills it.)

<GoPlayground>

```go
package main

import (
	"context"
	"errors"
	"fmt"
	"net/http"
	"net/http/httptest"
	"time"
)

func main() {
	// A server that accepts the request and then never answers.
	hung := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		<-r.Context().Done() // sit here until the client hangs up
	}))
	defer hung.Close()

	client := &http.Client{Timeout: 300 * time.Millisecond}

	start := time.Now()
	_, err := client.Get(hung.URL)
	fmt.Println("gave up after:", time.Since(start).Round(100*time.Millisecond))
	fmt.Println("error:", err)
	fmt.Println("is a deadline error:", errors.Is(err, context.DeadlineExceeded))
}
```

</GoPlayground>

```text
gave up after: 300ms
error: Get "http://127.0.0.1:53890": context deadline exceeded (Client.Timeout exceeded while awaiting headers)
is a deadline error: true
```

Read the error from the end: it gave up *while awaiting headers*, which tells you the server accepted the request and never started answering. Because the error wraps `context.DeadlineExceeded`, your code can detect a timeout with `errors.Is`, without matching on text. (The port number changes on every run.)

### Step 5: the fix, and how to read it

```go
var paymentClient = &http.Client{Timeout: 5 * time.Second}
```

Read it right to left: build an `http.Client` value with `Timeout` set (every other field keeps its zero value), then `&` takes its address, so `paymentClient` is a *pointer* to that one client. Everything that uses `paymentClient` shares the same client, and through it the same pool of connections.

`Timeout` covers the **whole** exchange: connecting, TLS, sending, waiting for headers, *and* reading the body. If all of that doesn't finish in five seconds, the call returns an error.

<Define term="http.Client (and the no-timeout trap)" since="Reliability Patterns (Part 2)">
`http.Client` holds the policy for outgoing requests: the overall `Timeout`, redirect rules, the cookie jar, and which `Transport` does the networking. Its zero value, which is exactly what `http.DefaultClient` is, has **no timeout**. If a server accepts the request and never answers, the call blocks forever. Build your own client with a `Timeout` for any code that calls a service you don't control, and reuse it.
</Define>

### Step 2: which setting guards which phase

| Phase | Setting | `DefaultTransport` value | A sane start for an API call |
|---|---|---|---|
| DNS + TCP connect | `net.Dialer{Timeout}` | 30 s | 3 s |
| TLS handshake | `Transport.TLSHandshakeTimeout` | 10 s | 5 s |
| Wait for headers | `Transport.ResponseHeaderTimeout` | none | 5 s |
| Read the body | only `Client.Timeout` or a context deadline | none | covered by `Client.Timeout` |
| Everything | `Client.Timeout` | none (on `DefaultClient`) | 10 s |

Those numbers come from the Go 1.27 source (`net/http/transport.go`), not memory. When a client has no `Transport` of its own, it uses `http.DefaultTransport`, so the first two rows apply to you even if you never mention a Transport.

### Step 3: start from a copy of `DefaultTransport`, not an empty one

The obvious way to set phase timeouts is to write `&http.Transport{...}` with the fields you care about. That quietly throws away everything `DefaultTransport` configures: reading proxy settings from the environment, HTTP/2, the dial timeout, and the idle-connection limits. The safe pattern is to **clone** the default and change what you need.

This program asks an HTTPS test server that speaks HTTP/2 the same question, once through a bare Transport literal and once through a clone:

<GoPlayground>

```go
package main

import (
	"fmt"
	"net/http"
	"net/http/httptest"
	"time"
)

func main() {
	// An HTTPS test server that speaks HTTP/2.
	srv := httptest.NewUnstartedServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {}))
	srv.EnableHTTP2 = true
	srv.StartTLS()
	defer srv.Close()
	trust := srv.Client().Transport.(*http.Transport).TLSClientConfig // trusts the test certificate

	// A: a brand-new Transport literal, one timeout set.
	bare := &http.Transport{TLSClientConfig: trust.Clone(), TLSHandshakeTimeout: 5 * time.Second}

	// B: a copy of DefaultTransport, then the same change.
	cloned := http.DefaultTransport.(*http.Transport).Clone()
	cloned.TLSClientConfig = trust.Clone()
	cloned.TLSHandshakeTimeout = 5 * time.Second

	for _, c := range []struct {
		name string
		tr   *http.Transport
	}{{"bare literal", bare}, {"cloned default", cloned}} {
		resp, err := (&http.Client{Transport: c.tr}).Get(srv.URL)
		if err != nil {
			fmt.Println(c.name, "error:", err)
			continue
		}
		resp.Body.Close()
		fmt.Printf("%-15s protocol=%s  uses proxy settings=%v  MaxIdleConns=%d\n",
			c.name, resp.Proto, c.tr.Proxy != nil, c.tr.MaxIdleConns)
	}
}
```

</GoPlayground>

```text
bare literal    protocol=HTTP/1.1  uses proxy settings=false  MaxIdleConns=0
cloned default  protocol=HTTP/2.0  uses proxy settings=true  MaxIdleConns=100
```

Same server, same timeout, different result. The bare literal fell back to HTTP/1.1: once you give a Transport a custom TLS config or dialer, Go only tries HTTP/2 if `ForceAttemptHTTP2` is true, and `DefaultTransport` sets that for you. The bare literal also ignores `HTTPS_PROXY`, and its `MaxIdleConns` of 0 means "no limit".

Two pieces of syntax in that line are worth reading slowly:

- `http.DefaultTransport.(*http.Transport)` is a **type assertion**. `DefaultTransport` is declared as the interface `http.RoundTripper`; the assertion says "I know the concrete value inside is a `*http.Transport`, give me that".
- `.Clone()` returns a deep copy, so changing the copy never touches the shared default that every other client in the program uses.

The production-shaped constructor looks like this:

```go
func newPaymentClient() *http.Client {
	tr := http.DefaultTransport.(*http.Transport).Clone()
	tr.DialContext = (&net.Dialer{Timeout: 3 * time.Second, KeepAlive: 30 * time.Second}).DialContext
	tr.TLSHandshakeTimeout = 5 * time.Second
	tr.ResponseHeaderTimeout = 5 * time.Second
	tr.MaxIdleConnsPerHost = 10 // Stop 3 explains this one
	return &http.Client{Transport: tr, Timeout: 10 * time.Second}
}
```

### Step 4: the phase timeout and the ceiling catch different failures

Two misbehaving servers. The first thinks for half a second before sending anything. The second sends its headers at once and then drips the body one byte every 100 ms. Watch which client catches which:

<GoPlayground>

```go
package main

import (
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
	"strings"
	"time"
)

func main() {
	// Server 1 thinks for half a second before sending anything.
	slowHeaders := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		time.Sleep(500 * time.Millisecond)
		fmt.Fprint(w, "ok")
	}))
	defer slowHeaders.Close()

	// Server 2 sends its headers at once, then drips the body: 1 byte per 100 ms.
	slowBody := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		w.(http.Flusher).Flush()
		for range 10 {
			fmt.Fprint(w, "x")
			w.(http.Flusher).Flush()
			time.Sleep(100 * time.Millisecond)
		}
	}))
	defer slowBody.Close()

	tr := http.DefaultTransport.(*http.Transport).Clone()
	tr.ResponseHeaderTimeout = 200 * time.Millisecond

	phaseOnly := &http.Client{Transport: tr}
	withCeiling := &http.Client{Transport: tr, Timeout: 500 * time.Millisecond}

	try("slow headers, phase timeout only ", phaseOnly, slowHeaders.URL)
	try("slow body,    phase timeout only ", phaseOnly, slowBody.URL)
	try("slow body,    + Client.Timeout   ", withCeiling, slowBody.URL)
}

func try(name string, c *http.Client, url string) {
	start := time.Now()
	resp, err := c.Get(url)
	if err == nil {
		_, err = io.ReadAll(resp.Body)
		resp.Body.Close()
	}
	took := time.Since(start).Round(100 * time.Millisecond)
	if err != nil {
		msg := strings.ReplaceAll(err.Error(), url, "URL") // hide the random port
		fmt.Printf("%s -> failed after %v\n    %s\n", name, took, msg)
		return
	}
	fmt.Printf("%s -> succeeded after %v\n", name, took)
}
```

</GoPlayground>

```text
slow headers, phase timeout only  -> failed after 200ms
    Get "URL": net/http: timeout awaiting response headers
slow body,    phase timeout only  -> succeeded after 1s
slow body,    + Client.Timeout    -> failed after 500ms
    context deadline exceeded (Client.Timeout or context cancellation while reading body)
```

Line two is the lesson. `ResponseHeaderTimeout` stopped the silent server in 200 ms, but it happily let the drip-feed server take a full second, because headers arrived instantly. Scale the drip to one byte a minute and that call takes hours. Only the whole-call ceiling, `Client.Timeout`, catches a slow body.

**Recap.** Clone `DefaultTransport`, set the phase timeouts you need, and always set `Client.Timeout` as the ceiling, because nothing else guards the body.

## Transport and Connection Pooling

*Stop 3 of 6.*

### Step 1: why keep connections open at all

From ch15: a new HTTPS connection costs a TCP handshake plus a TLS handshake, two or three network round trips before the first byte of your request moves. To a server 50 ms away, that's 100–150 ms of pure setup.

So when a response is finished, the Transport doesn't hang up. It parks the connection in an **idle pool**, keyed by scheme, host and port. The next request to the same place takes it from the pool and skips the handshakes. Press play: each chip is one TCP connection.

### Step 2: share one Transport (the Client matters less than you think)

You'll often hear "never create an `http.Client` per request". The real rule is narrower: **never create a Transport per request**, because the pool lives in the Transport. A `Client` with no `Transport` of its own uses the shared `http.DefaultTransport`, pool included.

This program counts the connections the server accepts across five calls, under four habits:

```go
package main

import (
	"fmt"
	"io"
	"net"
	"net/http"
	"net/http/httptest"
	"strings"
	"sync/atomic"
	"time"
)

func main() {
	var dials atomic.Int32            // counts every NEW connection the server accepts
	big := strings.Repeat("x", 1<<20) // a 1 MiB response
	srv := httptest.NewUnstartedServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		fmt.Fprint(w, big)
	}))
	srv.Config.ConnState = func(_ net.Conn, s http.ConnState) {
		if s == http.StateNew {
			dials.Add(1)
		}
	}
	srv.Start()
	defer srv.Close()

	measure := func(name string, call func()) {
		dials.Store(0)
		for range 5 {
			call()
		}
		time.Sleep(20 * time.Millisecond)
		fmt.Printf("%-40s 5 calls -> %d new connections\n", name, dials.Load())
	}
	readAndClose := func(resp *http.Response) {
		io.Copy(io.Discard, resp.Body)
		resp.Body.Close()
	}

	shared := &http.Client{Timeout: 5 * time.Second, Transport: http.DefaultTransport.(*http.Transport).Clone()}
	measure("A: one shared client, body drained", func() {
		resp, _ := shared.Get(srv.URL)
		readAndClose(resp)
	})
	measure("B: new Client per call, no Transport", func() {
		c := &http.Client{Timeout: 5 * time.Second} // Transport nil -> DefaultTransport
		resp, _ := c.Get(srv.URL)
		readAndClose(resp)
	})
	measure("C: new Transport per call", func() {
		c := &http.Client{Timeout: 5 * time.Second, Transport: &http.Transport{}}
		resp, _ := c.Get(srv.URL)
		readAndClose(resp)
	})
	fresh := &http.Client{Timeout: 5 * time.Second, Transport: http.DefaultTransport.(*http.Transport).Clone()}
	measure("D: one client, Close() without reading", func() {
		resp, _ := fresh.Get(srv.URL)
		resp.Body.Close()
	})
}
```

```text
B: new Client per call, no Transport     5 calls -> 1 new connections
```

- **A** is the goal: one handshake, four reuses.
- **B** surprises people: five separate `Client` values, still one connection, because all five share `DefaultTransport`. (Still, keep one client: it's where your timeout and settings live.)
- **C** is the real anti-pattern. Every new Transport starts with an empty pool, so every call pays the full handshake, and the old pools' idle connections linger until they time out.
- **D** closes a 1 MiB body it never read. Each connection still has unread bytes on it, so it can't be reused.

<Define term="http.Transport (connection pool and keep-alive)">
`http.Transport` is the layer under `http.Client` that owns the connections. It dials, does TLS, and keeps finished connections in an idle pool keyed by scheme, host and port, so the next request to the same place can skip the handshakes. Build one Transport at startup and share it: a new Transport means a new, empty pool.
</Define>

### Step 3: the body rule

A response body is a live stream on the connection. So:

1. **Always close it.** An unclosed body keeps its connection and a goroutine busy forever (conn 2 in the animation).
2. **Read it to the end before closing, if you want the connection back.** Unread bytes are still on the wire; the connection can't carry the next response until they're gone.

When you don't need the bytes, the idiom is:

```go
defer resp.Body.Close()
_, _ = io.Copy(io.Discard, resp.Body) // read the rest and throw it away
```

`io.Discard` is a writer that accepts everything and keeps nothing, so `io.Copy` just drains the stream.

<Callout kind="note" title="New in Go 1.27: the Transport rescues small bodies for you">

Starting with Go 1.27, when you close an HTTP/1 body early, the Transport itself tries to read what's left: at most 256 KiB, for at most 50 ms. If it reaches the end in that budget, the connection goes back to the pool. That's why habit D above used a 1 MiB body: with a small one, most of the connections would have been saved. Don't lean on it. Big or slow bodies still kill the connection, and code built with older Go versions gets no rescue at all. Drain explicitly.

</Callout>

<Define term="The drain-and-close body rule">
After every HTTP response, **close the body**, or the connection and its goroutine leak. To get the connection back into the pool, also **read the body to the end** first, for example with `io.Copy(io.Discard, resp.Body)`. Closing an unread body makes the Transport discard the connection, so the next request pays for a new handshake.
</Define>

### Step 4: sizing the pool

<ConceptGrid cols={3}>
  <ConceptCard label="MaxIdleConnsPerHost">Idle connections kept per host. The default is **2**. If you routinely have 20 calls in flight to one API, 18 of them close after every burst and redial on the next. Set it near your normal concurrency to that host (10–50 is common).</ConceptCard>
  <ConceptCard label="MaxIdleConns">Idle connections kept across all hosts. `DefaultTransport` sets 100; the zero value means no limit. Raise it if you talk to many hosts.</ConceptCard>
  <ConceptCard label="IdleConnTimeout">How long an idle connection may sit in the pool before the Transport closes it. `DefaultTransport` sets 90 s. Keep it below the server's or load balancer's own idle timeout, so the other side doesn't close it first.</ConceptCard>
  <ConceptCard label="MaxConnsPerHost">A hard cap on total connections (idle + busy) to one host. 0 means no cap. Requests beyond the cap wait for a free connection. Use it to avoid flooding a fragile dependency.</ConceptCard>
  <ConceptCard label="One Transport, injected">Build the client and its Transport once at startup and pass it to whatever needs it. The pool only helps if everyone shares it.</ConceptCard>
  <Gotcha>`MaxIdleConnsPerHost` is per host, so ten different API hosts can each keep their own idle connections. What stops the total growing is `MaxIdleConns`.</Gotcha>
</ConceptGrid>

<UnderTheHood title="The pool in more detail (Go 1.27)">

**The pool key.** Connections are pooled by scheme, host and port (plus proxy details). `http://api.example.com` and `https://api.example.com` never share a connection.

**HTTP/2 is different.** Over HTTP/2, one connection carries many requests at once as separate streams (ch15), so the Transport usually keeps a single connection per host and multiplexes everything onto it. Closing an unread HTTP/2 body resets just that stream; the connection survives. The drain rule is an HTTP/1.1 rule, but always closing is universal.

**The Transport already retries once, quietly.** A pooled connection can die while it sits idle (the server timed it out). If a request fails on a *reused* connection before any response arrived, and the request is safe to replay (a `GET`, `HEAD`, `OPTIONS` or `TRACE`, or anything carrying an `Idempotency-Key` header, with no body or a body it can rewind), the Transport retries it on a fresh connection before you ever see an error. Your own retries (Stop 5) sit on top of that.

**TCP keepalive.** `net.Dialer.KeepAlive` (30 s in `DefaultTransport`) makes the kernel send probes on quiet connections. If a NAT or load balancer silently dropped the connection, the probes fail and the socket errors out instead of hanging.

**Go 1.26: typed dial methods.** `net.Dialer` gained `DialTCP`, `DialUDP`, `DialIP` and `DialUnix`, which take a context and return the concrete connection types. They're for raw socket code. `http.Transport` still uses the `DialContext` field.

</UnderTheHood>

**Recap.** One Transport, shared. Close every body; drain it when you want the connection back. Raise `MaxIdleConnsPerHost` above the default 2 when you call one host a lot.

### Step 2: the one call that wires it up

```go
req, err := http.NewRequestWithContext(ctx, http.MethodPost, url, body)
if err != nil {
	return err // only fails for a bad method or URL
}
resp, err := client.Do(req)
```

`NewRequestWithContext` builds the `*http.Request` and attaches `ctx`. `client.Do(req)` sends it. From then on the request stops at whichever comes first: the context's deadline, the context being cancelled, or `Client.Timeout`. You don't choose between them; both clocks run and the earlier one wins.

Inside an HTTP handler, the context you want is `r.Context()`. It's cancelled when the incoming request's client disconnects or the server shuts down, so your outbound call stops with it.

<Callout kind="note" title="http.NewRequest vs http.NewRequestWithContext">

`http.NewRequest(method, url, body)` is `NewRequestWithContext` with `context.Background()`: a context that is never cancelled and has no deadline. Fine in a one-off script. In a server, it silently cuts the chain of cancellation, so use `NewRequestWithContext` and pass along the context you were given. The context chapter (Part 1, Chapter 7) covers where contexts come from.

</Callout>

When it passes, `ctx.Done()` closes, and everything holding that context (HTTP calls, database queries) is told to stop. Unlike `Client.Timeout`, it belongs to one request and is passed down the whole call chain.

## Retries

*Stop 5 of 6.*

<Define term="Retry with exponential backoff and jitter" since="Reliability Patterns (Part 2)">
A **retry** re-sends a request that failed for a reason that might pass: a dropped connection, a 503 from an overloaded server. **Exponential backoff** doubles the wait before each new try (100 ms, 200 ms, 400 ms…) so a struggling server gets breathing room. **Jitter** makes each wait random, so thousands of clients that failed at the same moment don't all retry at the same moment too.
</Define>

### Step 1: which failures deserve a second try

A retry only helps if the next attempt could turn out differently, and only if sending the request twice is safe.

| Result | Retry? | Why |
|---|---|---|
| Network error (connection refused, reset, timeout) | Yes, if the request is safe to repeat | The server may never have seen it, or had a blip |
| 502, 503, 504 | Yes | A proxy or server says "not right now" |
| 429 Too Many Requests | Yes, after waiting (honour a `Retry-After` header if present) | You're being rate-limited |
| 500 | Usually | Often a transient bug or dependency failure |
| 400, 401, 403, 404, 422 | No | Your request is wrong; sending it again gives the same answer |

**Safe to repeat** means *idempotent*: doing it twice has the same effect as doing it once. `GET` and `HEAD` are. `POST /charge` is not: if the first attempt reached the server and only the response was lost, a retry charges the customer twice. Payment APIs solve this with an **idempotency key**: you send a unique `Idempotency-Key` header, and the server recognises a repeat and returns the first result instead of charging again.

```go
package main

import (
	"context"
	"fmt"
	"io"
	"math/rand/v2"
	"net/http"
	"net/http/httptest"
	"sync/atomic"
	"time"

// retryable reports whether trying again could give a different answer.
func retryable(status int) bool {
	return status == http.StatusTooManyRequests || status >= 500
}

func getWithRetry(ctx context.Context, client *http.Client, url string, attempts int) (string, error) {
	backoff := 100 * time.Millisecond
	const maxBackoff = 2 * time.Second

	for attempt := 1; ; attempt++ {
		body, status, err := getOnce(ctx, client, url)
		if err == nil && !retryable(status) {
			if status != http.StatusOK {
				return "", fmt.Errorf("status %d (not retryable)", status)
			}
			return body, nil
		}
		if attempt == attempts {
			return "", fmt.Errorf("gave up after %d attempts (last: status=%d err=%v)", attempts, status, err)
		}

		// Full jitter: wait a random time between 0 and backoff.
		wait := rand.N(backoff)
		fmt.Printf("attempt %d: status=%d err=%v -> waiting up to %v\n", attempt, status, err, backoff)
		select {
		case <-ctx.Done():
			return "", ctx.Err()
		case <-time.After(wait):
		}
		backoff = min(backoff*2, maxBackoff)
	}
}

// getOnce makes one request and always closes the body.
func getOnce(ctx context.Context, client *http.Client, url string) (string, int, error) {
	req, err := http.NewRequestWithContext(ctx, http.MethodGet, url, nil)
	if err != nil {
		return "", 0, err
	}
	resp, err := client.Do(req)
	if err != nil {
		return "", 0, err
	}
	defer resp.Body.Close()
	body, err := io.ReadAll(io.LimitReader(resp.Body, 1<<20))
	return string(body), resp.StatusCode, err
}

func main() {
	var calls atomic.Int32
	flaky := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		if calls.Add(1) < 3 { // the first two calls fail
			w.WriteHeader(http.StatusServiceUnavailable)
			return
		}
		fmt.Fprint(w, "rate: 1.0823")
	}))
	defer flaky.Close()

	client := &http.Client{Timeout: 3 * time.Second}
	body, err := getWithRetry(context.Background(), client, flaky.URL, 4)
	fmt.Println("result:", body, err)
}
```

```text
attempt 1: status=503 err=<nil> -> waiting up to 100ms
attempt 2: status=503 err=<nil> -> waiting up to 200ms
result: rate: 1.0823 <nil>
```

Three details that are easy to get wrong:

- **The wait is inside a `select` on `ctx.Done()`.** If the caller gives up during a backoff, the loop returns at once instead of sleeping on.
- **`getOnce` always closes the body**, including on 5xx, so failed attempts don't leak connections.
- **Request bodies can only be read once.** This loop builds a fresh request per attempt, which is the simple fix. If you reuse a request that has a body, it must have `GetBody` set so the body can be rewound; `http.NewRequest` sets it for you when the body is a `*bytes.Buffer`, `*bytes.Reader` or `*strings.Reader`.

<Callout kind="warn" title="Retries multiply load">

Three attempts per call means a failing dependency sees up to three times the traffic, exactly when it's weakest. Part 2's "Reliability Patterns" chapter (Chapter 12) adds the guard rails: retry budgets, circuit breakers that stop calling a clearly broken service, and honouring `Retry-After`. For now: few attempts, backoff with jitter, and only for requests that are safe to repeat.

</Callout>

**Recap.** Retry only what could succeed next time and is safe to send twice. Back off exponentially, randomise every wait, cap the attempts, and stop when the context ends.

```go
import (
	"encoding/json"
	"fmt"
	"io"
	"mime"
	"net/http"
	"net/http/httptest"
	"strings"
	"time"
)

type ExchangeRate struct {
	From string `json:"from"`
	To   string `json:"to"`
	Rate int64  `json:"rate_millionths"` // 1082300 means 1.0823
}

const maxBodyBytes = 1 << 20 // 1 MiB: a rate has no business being bigger

var rateClient = &http.Client{Timeout: 5 * time.Second}

func fetchRate(url string) (*ExchangeRate, error) {
	resp, err := rateClient.Get(url)
	if err != nil {
		return nil, fmt.Errorf("fetchRate: %w", err)
	}
	defer resp.Body.Close()

	// Gate 1: the status code, before touching the body.
	if resp.StatusCode != http.StatusOK {
		preview, _ := io.ReadAll(io.LimitReader(resp.Body, 200))
		return nil, fmt.Errorf("fetchRate: status %d: %q", resp.StatusCode, preview)
	}
	// Gate 2: the Content-Type.
	mt, _, _ := mime.ParseMediaType(resp.Header.Get("Content-Type"))
	if mt != "application/json" {
		return nil, fmt.Errorf("fetchRate: want JSON, got %q", mt)
	}
	// Gate 3 + 4: cap the size, then stream-decode.
	var rate ExchangeRate
	dec := json.NewDecoder(io.LimitReader(resp.Body, maxBodyBytes))
	if err := dec.Decode(&rate); err != nil {
		return nil, fmt.Errorf("fetchRate: decode: %w", err)
	}
	return &rate, nil
}

func main() {
	serve := func(status int, ctype, body string) *httptest.Server {
		return httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
			w.Header().Set("Content-Type", ctype)
			w.WriteHeader(status)
			fmt.Fprint(w, body)
		}))
	}
	cases := []struct {
		name string
		srv  *httptest.Server
	}{

		{"huge body", serve(200, "application/json", `{"from":"`+strings.Repeat("A", 2<<20)+`"}`)},

		c.srv.Close()
		if err != nil {
			fmt.Printf("%-13s error: %v\n", c.name, err)
```

  <ConceptCard label="io.LimitReader">Wraps a reader and reports end-of-stream after N bytes. Without it, a broken or hostile server can stream gigabytes into your process.</ConceptCard>

<Callout kind="note" title="io.ReadAll got cheaper in Go 1.26">

Go 1.26 reworked `io.ReadAll`: it grows its buffer in chunks and builds one right-sized slice at the end, instead of growing a single slice by repeated appends. The release notes report it as often about twice as fast with roughly half the total memory. That makes `io.ReadAll` an even more reasonable choice for small bodies, but it's still unbounded: wrap the body in `io.LimitReader` first.

</Callout>

<Exercise n={3} title="Safe JSON decode" level="medium">

Write `decodePriceResponse(resp *http.Response, out any) error` that:
1. Returns an error if status is not 200, including the first 512 bytes of the body in the error message.
2. Wraps the body in `io.LimitReader` with a 512 KB cap before decoding.
3. Uses `json.NewDecoder` to decode into `out`.
4. Always drains and closes the body.

<Solution>

```go
package main

import (
	"encoding/json"
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
	"time"
)

func decodePriceResponse(resp *http.Response, out any) error {
	defer resp.Body.Close()
	// Always drain so the connection can be reused.
	// Defers run LIFO: drain fires first (body still open), then close.
	defer func() { _, _ = io.Copy(io.Discard, resp.Body) }()

	if resp.StatusCode != http.StatusOK {
		preview, _ := io.ReadAll(io.LimitReader(resp.Body, 512))
		return fmt.Errorf("unexpected status %d: %s", resp.StatusCode, preview)
	}

	limited := io.LimitReader(resp.Body, 512*1024) // 512 KiB
	return json.NewDecoder(limited).Decode(out)
}

type Price struct {
	Amount   int64  `json:"amount_cents"`
	Currency string `json:"currency"`
}

func main() {
	srv := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		w.Header().Set("Content-Type", "application/json")
		fmt.Fprintln(w, `{"amount_cents":4999,"currency":"USD"}`)
	}))
	defer srv.Close()

	client := &http.Client{Timeout: 5 * time.Second}
	resp, err := client.Get(srv.URL)
	if err != nil {
		fmt.Println("error:", err)
		return
	}

	var p Price
	if err := decodePriceResponse(resp, &p); err != nil {
		fmt.Println("error:", err)
		return
	}
	fmt.Printf("price: %d cents %s\n", p.Amount, p.Currency)
}
```

The two defers run last-in, first-out: the drain runs first (the body is still open, and any unread bytes are discarded), then `resp.Body.Close()`. On the error path, the preview may not have read everything; the drain finishes the job. On the success path, the decoder stops after the first JSON value, which can leave bytes unread on a larger body; the drain reads them.

</Solution>

<Exercise n={4} title="Retry with backoff" level="medium">

Write `getWithRetry(ctx context.Context, client *http.Client, url string, maxAttempts int) (*http.Response, error)` that retries on network errors and 5xx status codes with exponential backoff starting at 100ms and capped at 1s. Only attempt the retry if the context is not yet done.

<Solution>

```go
package main

import (
	"context"
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
	"sync/atomic"
	"time"
)

func getWithRetry(ctx context.Context, client *http.Client, url string, maxAttempts int) (*http.Response, error) {
	base := 100 * time.Millisecond
	maxDelay := 1 * time.Second

	for attempt := 0; attempt < maxAttempts; attempt++ {
		if attempt > 0 {
			delay := min(base<<(attempt-1), maxDelay)
			select {
			case <-ctx.Done():
				return nil, fmt.Errorf("context cancelled during backoff: %w", ctx.Err())
			case <-time.After(delay):
			}
		}

		req, err := http.NewRequestWithContext(ctx, http.MethodGet, url, nil)
		if err != nil {
			return nil, err
		}

		resp, err := client.Do(req)
		if err != nil {
			fmt.Printf("attempt %d: error: %v\n", attempt+1, err)
			continue
		}
		if resp.StatusCode >= 500 {
			_, _ = io.Copy(io.Discard, resp.Body)
			resp.Body.Close()
			fmt.Printf("attempt %d: 5xx %d\n", attempt+1, resp.StatusCode)
			continue
		}
		return resp, nil
	}
	return nil, fmt.Errorf("all %d attempts failed", maxAttempts)
}

func main() {
	var n atomic.Int32
	srv := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		if n.Add(1) < 3 {
			w.WriteHeader(503)
			return
		}
		fmt.Fprintln(w, "ok")
	}))
	defer srv.Close()

	ctx := context.Background()
	client := &http.Client{Timeout: 3 * time.Second}
	resp, err := getWithRetry(ctx, client, srv.URL, 5)
	if err != nil {
		fmt.Println("error:", err)
		return
	}
	defer resp.Body.Close()
	body, _ := io.ReadAll(resp.Body)
	fmt.Println("response:", string(body))
}
```

`base<<(attempt-1)` doubles the delay each time (a left shift by one bit multiplies by two), and `min` caps it. The `select` on `ctx.Done()` makes the backoff sleep cancellable. For production, add jitter as in Stop 5.

</Solution>

</Exercise>

```go
package main

import (
	"context"
	"encoding/json"
	"fmt"
	"io"
	"mime"
	"net/http"
	"net/http/httptest"
	"sync/atomic"
	"time"
)

type RateService struct {
	client *http.Client
	base   string
}

func NewRateService(baseURL string) *RateService {
	tr := http.DefaultTransport.(*http.Transport).Clone()
	tr.MaxIdleConnsPerHost = 5
	return &RateService{
		client: &http.Client{Timeout: 6 * time.Second, Transport: tr},
		base:   baseURL,
	}
}

type rateResponse struct {
	Rate int64 `json:"rate_millionths"`
}

func (s *RateService) FetchRate(ctx context.Context, from, to string) (int64, error) {
	url := fmt.Sprintf("%s/rates/%s/%s", s.base, from, to)
	baseDelay := 200 * time.Millisecond

	for attempt := 0; attempt < 3; attempt++ {
		if attempt > 0 {
			select {
			case <-ctx.Done():
				return 0, fmt.Errorf("FetchRate: context done in backoff: %w", ctx.Err())
			case <-time.After(baseDelay << (attempt - 1)):
			}
		}

		req, err := http.NewRequestWithContext(ctx, http.MethodGet, url, nil)
		if err != nil {
			return 0, fmt.Errorf("FetchRate: build request: %w", err)
		}

		resp, err := s.client.Do(req)
		if err != nil {
			continue // network error: retry
		}

		if resp.StatusCode >= 500 {
			_, _ = io.Copy(io.Discard, resp.Body)
			resp.Body.Close()
			continue
		}

		// Non-retryable path: handle here, close explicitly (no defer inside a loop).
		if resp.StatusCode != http.StatusOK {
			b, _ := io.ReadAll(io.LimitReader(resp.Body, 512))
			resp.Body.Close()
			return 0, fmt.Errorf("FetchRate: status %d: %s", resp.StatusCode, b)
		}
		if mt, _, _ := mime.ParseMediaType(resp.Header.Get("Content-Type")); mt != "application/json" {
			_, _ = io.Copy(io.Discard, resp.Body)
			resp.Body.Close()
			return 0, fmt.Errorf("FetchRate: unexpected content-type %q", mt)
		}

		var r rateResponse
		err = json.NewDecoder(io.LimitReader(resp.Body, 64*1024)).Decode(&r)
		_, _ = io.Copy(io.Discard, resp.Body) // drain trailing bytes
		resp.Body.Close()
		if err != nil {
			return 0, fmt.Errorf("FetchRate: decode: %w", err)
		}
		return r.Rate, nil
	}
	return 0, fmt.Errorf("FetchRate: all 3 attempts failed")
}

func main() {
	var calls atomic.Int32
	srv := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		n := calls.Add(1)
		if n < 3 {
			w.WriteHeader(503)
			return
		}
		w.Header().Set("Content-Type", "application/json")
		fmt.Fprintln(w, `{"rate_millionths":1082300}`)

	svc := NewRateService(srv.URL)

	if err != nil {
		fmt.Println("error:", err)
		return
	}
	fmt.Printf("rate: %d millionths (%.4f)\n", rate, float64(rate)/1_000_000)
}
```

<Recap>

- **`http.DefaultClient` has no timeout.** Build your own `&http.Client{Timeout: ...}` once and share it.
- **Timeouts layer.** Clone `http.DefaultTransport` and set the phase timeouts (dial, TLS, response headers) you need. `Client.Timeout` is the ceiling, and the only thing that guards a slow body.
- **The pool lives in the Transport.** Share one Transport; a new Transport per request means a new handshake per request. Raise `MaxIdleConnsPerHost` above the default of 2 when you call one host a lot.
- **Close every body; drain it to get the connection back.** `io.Copy(io.Discard, resp.Body)` before `Close()`. Go 1.27 rescues small bodies you close early, but don't rely on it.
- **`http.NewRequestWithContext`** passes the caller's deadline and cancellation into the outbound call. Cancelling stops your wait, not the server's work.
- **Retry only what's retryable and safe to repeat.** Exponential backoff, full jitter, a cap on attempts, and a `select` on `ctx.Done()` during every wait.
- **Decode defensively:** status, then Content-Type, then `io.LimitReader`, then `json.Decoder`.

</Recap>
