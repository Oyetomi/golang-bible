Here's the thing, sport. Every website you have ever opened started with a question you never saw asked: *what IP address is hiding behind this name?* A name like `api.example.com` is for humans. The network moves packets by IP — `93.184.216.34` — and the thing that translates one into the other is a **DNS resolver**. You're going to build one. Every stage is runnable, stdlib-only, and built on top of the last. By the end you'll never look at a slow page load the same way again — you'll know exactly which lookup is to blame.

## The Lookup Chain

Before any code, the mental model. No single machine knows every domain on the internet — that would be impossible to keep current. Instead the answer is found by walking a **chain** of servers, each one pointing you closer to the source.

<Define term="DNS record / zone / resolver" since="Networking & Web Fundamentals (Part 1)">
A **DNS record** maps a name to a value — most commonly an **A** record (name → IPv4 address). A **zone** is the set of records one server is authoritative for (e.g. everything under `example.com`). A **resolver** is the client-side machinery that, given a name and a record type, finds the answer — either from its **cache** or by walking the lookup chain to an **authoritative** server. The record's **TTL** (time-to-live, in seconds) says how long the answer may be cached before it must be looked up again.
</Define>

This chapter builds that machine bottom-up. We start with the thing at the *end* of the chain — the zone that actually holds records — then add the resolver, the cache, CNAME handling, zone transfer, and finally the output formatter. Six stages, each runnable on its own.

## Stage 1 · Records & the Zone

A zone is a store of records keyed by name. We model a `Record` (name, type, value, TTL) and a `Zone` that holds them and answers lookups by name **and** type — because one name can carry several records (an `A` and an `MX` and a `TXT`, say).

```go
package main

import "fmt"

// RecordType is the kind of a DNS record. A maps a name to an IPv4 address;
// AAAA to IPv6; CNAME aliases one name to another; MX names a mail server;
// TXT carries arbitrary text (SPF, domain verification, …).
type RecordType string

const (
	TypeA     RecordType = "A"
	TypeAAAA  RecordType = "AAAA"
	TypeCNAME RecordType = "CNAME"
	TypeMX    RecordType = "MX"
	TypeTXT   RecordType = "TXT"
)

// Record is a single DNS record. TTL is in seconds — how long an answer
// may be cached before it must be looked up again.
type Record struct {
	Name  string
	Type  RecordType
	Value string
	TTL   int
}

// Zone is an authoritative store of records for one origin (e.g. example.com).
// Records are indexed by name; a name can hold several records of different types.
type Zone struct {
	Origin  string
	records map[string][]Record
}

func NewZone(origin string) *Zone {
	return &Zone{Origin: origin, records: map[string][]Record{}}
}

// AddRecord stores a record under its name.
func (z *Zone) AddRecord(r Record) {
	z.records[r.Name] = append(z.records[r.Name], r)
}

// Lookup returns every record matching the name AND the query type.
// A query type of "" matches any type (used by zone transfer later).
func (z *Zone) Lookup(name string, qtype RecordType) []Record {
	var out []Record
	for _, r := range z.records[name] {
		if qtype == "" || r.Type == qtype {
			out = append(out, r)
		}
	}
	return out
}

func main() {
	zone := NewZone("example.com")
	zone.AddRecord(Record{Name: "api.example.com", Type: TypeA, Value: "93.184.216.34", TTL: 300})
	zone.AddRecord(Record{Name: "api.example.com", Type: TypeTXT, Value: "v=spf1 -all", TTL: 3600})
	zone.AddRecord(Record{Name: "cdn.example.com", Type: TypeCNAME, Value: "d1234.cloudfront.net", TTL: 3600})

	fmt.Printf("zone %q holds records for %d names\n", zone.Origin, len(zone.records))

	for _, r := range zone.Lookup("api.example.com", TypeA) {
		fmt.Printf("  %s %s -> %s (TTL %ds)\n", r.Name, r.Type, r.Value, r.TTL)
	}
	for _, r := range zone.Lookup("api.example.com", TypeTXT) {
		fmt.Printf("  %s %s -> %q (TTL %ds)\n", r.Name, r.Type, r.Value, r.TTL)
	}
}
```

## Stage 2 · Resolving a Name

The zone answers within itself. A **resolver** is the layer above: it takes a name and a type, and returns the answer — for now, straight from a zone, but with the shape that the cache and CNAME logic will slot into next. We also add the lookup chain in miniature: a resolver that holds **several** zones (root, the TLD, the authoritative zone) and follows delegation from one to the next.

```go
package main

import (
	"fmt"
	"strings"
)

type Record struct {
	Name, Type, Value string
	TTL               int
}

// Resolver holds a set of authoritative zones keyed by origin, plus the order
// to consult them — the in-memory stand-in for the root → TLD → authoritative
// chain. A real resolver would follow NS referrals over the network; here we
// model delegation by picking the most specific zone that owns the name.
type Resolver struct {
	zones map[string]map[string][]Record // origin -> name -> records
}

func NewResolver() *Resolver {
	return &Resolver{zones: map[string]map[string][]Record{}}
}

func (r *Resolver) AddZone(origin string) {
	r.zones[origin] = map[string][]Record{}
}

func (r *Resolver) AddRecord(origin string, rec Record) {
	r.zones[origin][rec.Name] = append(r.zones[origin][rec.Name], rec)
}

// zoneFor returns the most specific zone origin that the name falls under —
// the delegation step. "api.example.com" prefers the "example.com" zone over
// the "com" zone over the root ".".
func (r *Resolver) zoneFor(name string) string {
	best := ""
	for origin := range r.zones {
		if origin == "." || name == origin || strings.HasSuffix(name, "."+origin) {
			if len(origin) > len(best) {
				best = origin
			}
		}
	}
	return best
}

// Resolve walks to the zone that owns the name and returns matching records.
func (r *Resolver) Resolve(name, qtype string) ([]Record, error) {
	origin := r.zoneFor(name)
	if origin == "" {
		return nil, fmt.Errorf("no zone authoritative for %q", name)
	}
	var out []Record
	for _, rec := range r.zones[origin][name] {
		if rec.Type == qtype {
			out = append(out, rec)
		}
	}
	if len(out) == 0 {
		return nil, fmt.Errorf("NXDOMAIN: no %s record for %q (zone %q)", qtype, name, origin)
	}
	return out, nil
}

func main() {
	res := NewResolver()
	res.AddZone("example.com")
	res.AddZone("com")
	res.AddRecord("example.com", Record{Name: "api.example.com", Type: "A", Value: "93.184.216.34", TTL: 300})
	res.AddRecord("example.com", Record{Name: "www.example.com", Type: "A", Value: "93.184.216.35", TTL: 300})

	for _, q := range []string{"api.example.com", "www.example.com", "ghost.example.com"} {
		recs, err := res.Resolve(q, "A")
		if err != nil {
			fmt.Printf("%-22s -> %v\n", q, err)
			continue
		}
		fmt.Printf("%-22s -> %s (zone %q)\n", q, recs[0].Value, res.zoneFor(q))
	}
}
```

## Stage 3 · The TTL Cache

Walking the whole chain for every lookup would melt the internet. The fix is the **cache**: once a record is found, store it for its TTL and serve the next request straight from memory. When the TTL elapses, the entry is **stale** and must be looked up again. This is the same TTL-cache pattern as the Pokedex project (Part 1) and the caching chapter — here keyed by DNS name and expiring on the record's own TTL.

We inject a clock as a `func() time.Time` so the cache is deterministic in tests — fast-forward time instead of sleeping, the discipline from the **Time, Clocks & Timers** chapter.

```go
package main

import (
	"fmt"
	"time"
)

type Record struct {
	Name, Type, Value string
	TTL               int
}

type entry struct {
	record  Record
	expires time.Time
}

// Cache stores records until their TTL elapses. The clock is injected so tests
// can fast-forward time instead of sleeping.
type Cache struct {
	now     func() time.Time
	entries map[string]entry // key: name|type
}

func NewCache(now func() time.Time) *Cache {
	return &Cache{now: now, entries: map[string]entry{}}
}

func key(name, qtype string) string { return name + "|" + qtype }

// Get returns the cached record if present AND still fresh. A stale entry is
// treated as a miss (and lazily deleted) — the TTL has expired.
func (c *Cache) Get(name, qtype string) (Record, bool) {
	e, ok := c.entries[key(name, qtype)]
	if !ok {
		return Record{}, false
	}
	if !c.now().Before(e.expires) { // now >= expires -> stale
		delete(c.entries, key(name, qtype))
		return Record{}, false
	}
	return e.record, true
}

// Put stores a record with an expiry computed from its TTL.
func (c *Cache) Put(r Record) {
	c.entries[key(r.Name, r.Type)] = entry{
		record:  r,
		expires: c.now().Add(time.Duration(r.TTL) * time.Second),
	}
}

func main() {
	// A controllable clock: a pointer we advance by hand.
	clock := time.Date(2026, 1, 1, 12, 0, 0, 0, time.UTC)
	cache := NewCache(func() time.Time { return clock })

	cache.Put(Record{Name: "api.example.com", Type: "A", Value: "93.184.216.34", TTL: 300})

	// t+10s: still fresh — HIT.
	clock = clock.Add(10 * time.Second)
	if r, ok := cache.Get("api.example.com", "A"); ok {
		fmt.Printf("t+10s   HIT  -> %s\n", r.Value)
	}

	// t+301s: TTL was 300 — now stale, MISS.
	clock = clock.Add(291 * time.Second)
	if _, ok := cache.Get("api.example.com", "A"); !ok {
		fmt.Println("t+301s  MISS -> expired, must re-resolve")
	}

	fmt.Printf("entries after expiry sweep: %d\n", len(cache.entries))
}
```

```go
import (
	"fmt"
	"time"
)

type Record struct {
	Name, Type, Value string
	TTL               int
}

type entry struct {
	record  Record
	expires time.Time
}

type Cache struct {
	now     func() time.Time
	entries map[string]entry
}

func NewCache(now func() time.Time) *Cache {
	return &Cache{now: now, entries: map[string]entry{}}
}

func key(name, qtype string) string { return name + "|" + qtype }

func (c *Cache) Get(name, qtype string) (Record, bool) {
	e, ok := c.entries[key(name, qtype)]
	if !ok {
		return Record{}, false
	}
	if !c.now().Before(e.expires) {
		delete(c.entries, key(name, qtype))
		return Record{}, false
	}
	return e.record, true
}

func (c *Cache) Put(r Record) {
	c.entries[key(r.Name, r.Type)] = entry{
		record:  r,
		expires: c.now().Add(time.Duration(r.TTL) * time.Second),
	}
}

func main() {
	clock := time.Date(2026, 1, 1, 12, 0, 0, 0, time.UTC)
	cache := NewCache(func() time.Time { return clock })

	cache.Put(Record{Name: "api.example.com", Type: "A", Value: "93.184.216.34", TTL: 300})

	clock = clock.Add(10 * time.Second)
	if r, ok := cache.Get("api.example.com", "A"); ok {
		fmt.Printf("t+10s   HIT  -> %s\n", r.Value)
	}

	clock = clock.Add(291 * time.Second)
	if _, ok := cache.Get("api.example.com", "A"); !ok {
		fmt.Println("t+301s  MISS -> expired, must re-resolve")
	}

	fmt.Printf("entries after expiry sweep: %d\n", len(cache.entries))
```

<Gotcha>
A cache that ignores TTL is worse than no cache: after a server fails over to a new IP, every client still holding the old address keeps hammering a dead host until *someone* notices. The TTL is the failover budget. Honor it — `now >= expires` is a miss, no exceptions — and never cache a record for longer than its TTL says.

## Stage 4 · CNAMEs & Cycle Detection

A **CNAME** record aliases one name to another: `cdn.example.com` is really `d1234.cloudfront.net`. To resolve a CNAME you follow the alias to its target, then resolve *that* — possibly through more CNAMEs. The danger: a misconfiguration where `a → b → a` loops forever. A real resolver caps the chain and detects the cycle; so will yours.

```go
package main

import (
	"errors"
	"fmt"
)

type Record struct {
	Name, Type, Value string
	TTL               int
}

type DB struct {
	records map[string][]Record
}

func (db *DB) add(r Record) { db.records[r.Name] = append(db.records[r.Name], r) }

func (db *DB) first(name, qtype string) (Record, bool) {
	for _, r := range db.records[name] {
		if r.Type == qtype {
			return r, true
		}
	}
	return Record{}, false
}

const maxCNAMEDepth = 8

var errCNAMECycle = errors.New("CNAME cycle detected")

// resolveA follows CNAMEs until it reaches an A record, guarding against cycles
// with a visited-set and a hard depth cap. Returns the final A record plus the
// chain of names walked, so you can see exactly how the alias unwound.
func (db *DB) resolveA(name string) (Record, []string, error) {
	visited := map[string]bool{}
	chain := []string{}
	for depth := 0; depth < maxCNAMEDepth; depth++ {
		if visited[name] {
			return Record{}, chain, errCNAMECycle
		}
		visited[name] = true
		chain = append(chain, name)

		if a, ok := db.first(name, "A"); ok {
			return a, chain, nil // reached an address — done
		}
		cname, ok := db.first(name, "CNAME")
		if !ok {
			return Record{}, chain, fmt.Errorf("NXDOMAIN: no A or CNAME for %q", name)
		}
		name = cname.Value // follow the alias and loop
	}
	return Record{}, chain, fmt.Errorf("CNAME chain exceeded %d hops", maxCNAMEDepth)
}

func main() {
	db := &DB{records: map[string][]Record{}}
	// A healthy CNAME chain ending in an address.
	db.add(Record{Name: "cdn.example.com", Type: "CNAME", Value: "d1234.cloudfront.net", TTL: 3600})
	db.add(Record{Name: "d1234.cloudfront.net", Type: "A", Value: "13.32.0.1", TTL: 60})
	// A poisoned loop: a -> b -> a.
	db.add(Record{Name: "a.example.com", Type: "CNAME", Value: "b.example.com", TTL: 300})
	db.add(Record{Name: "b.example.com", Type: "CNAME", Value: "a.example.com", TTL: 300})

	rec, chain, err := db.resolveA("cdn.example.com")
	fmt.Printf("cdn.example.com: %v  via %v\n", rec.Value, chain)
	_ = err

	_, loopChain, err := db.resolveA("a.example.com")
	fmt.Printf("a.example.com:   %v  (walked %v)\n", err, loopChain)
}
```

## Stage 5 · Zone Transfer

A **zone transfer** (AXFR in real DNS) copies an entire zone from one server to another — how a secondary nameserver mirrors the primary. We implement the dump side: serialize every record in the zone in a stable order so two servers can compare and sync. Stable order matters — a diff between primary and secondary must be deterministic.

```go
package main

import (
	"fmt"
	"sort"
	"strings"
)

type Record struct {
	Name, Type, Value string
	TTL               int
}

type Zone struct {
	Origin  string
	records map[string][]Record
}

func NewZone(origin string) *Zone { return &Zone{Origin: origin, records: map[string][]Record{}} }
func (z *Zone) AddRecord(r Record) { z.records[r.Name] = append(z.records[r.Name], r) }

// Transfer returns every record in the zone in a stable order (by name, then
// type, then value) — the AXFR dump a secondary nameserver consumes to mirror
// the primary. Stable order makes primary/secondary diffs deterministic.
func (z *Zone) Transfer() []Record {
	var all []Record
	for _, recs := range z.records {
		all = append(all, recs...)
	}
	sort.Slice(all, func(i, j int) bool {
		if all[i].Name != all[j].Name {
			return all[i].Name < all[j].Name
		}
		if all[i].Type != all[j].Type {
			return all[i].Type < all[j].Type
		}
		return all[i].Value < all[j].Value
	})
	return all
}

func main() {
	z := NewZone("example.com")
	z.AddRecord(Record{Name: "www.example.com", Type: "A", Value: "93.184.216.35", TTL: 300})
	z.AddRecord(Record{Name: "api.example.com", Type: "A", Value: "93.184.216.34", TTL: 300})
	z.AddRecord(Record{Name: "api.example.com", Type: "TXT", Value: "v=spf1 -all", TTL: 3600})
	z.AddRecord(Record{Name: "example.com", Type: "MX", Value: "10 mail.example.com", TTL: 3600})

	fmt.Printf("; AXFR transfer of zone %s (%d records)\n", z.Origin, len(z.Transfer()))
	for _, r := range z.Transfer() {
		fmt.Printf("%-20s %5d IN %-5s %s\n", r.Name, r.TTL, r.Type, strings.TrimSpace(r.Value))
	}
}
```

## Stage 6 · dig-Style Output

The capstone of usability: format a resolution result the way `dig`, the standard DNS tool, does — a header with status and timing, a question section, and an answer section in zone-file form. Engineers read `dig` output all day; matching it makes your resolver instantly familiar.

```go
package main

import (
	"fmt"
	"strings"
	"time"
)

type Record struct {
	Name, Type, Value string
	TTL               int
}

// Answer is one resolution result: the question asked, the records found,
// the status, and how long the lookup took.
type Answer struct {
	QName    string
	QType    string
	Status   string // NOERROR, NXDOMAIN, SERVFAIL
	Records  []Record
	Elapsed  time.Duration
}

// Dig formats an Answer the way the `dig` command-line tool does.
func Dig(a Answer) string {
	var b strings.Builder
	fmt.Fprintf(&b, ";; ->>HEADER<<- opcode: QUERY, status: %s\n", a.Status)
	fmt.Fprintf(&b, ";; QUESTION SECTION:\n;%s.\tIN\t%s\n\n", a.QName, a.QType)

	if len(a.Records) > 0 {
		fmt.Fprintf(&b, ";; ANSWER SECTION:\n")
		for _, r := range a.Records {
			fmt.Fprintf(&b, "%s.\t%d\tIN\t%s\t%s\n", r.Name, r.TTL, r.Type, r.Value)
		}
		fmt.Fprintln(&b)
	}
	fmt.Fprintf(&b, ";; Query time: %d ms\n", a.Elapsed.Milliseconds())
	return b.String()
}

func main() {
	ans := Answer{
		QName:  "api.example.com",
		QType:  "A",
		Status: "NOERROR",
		Records: []Record{
			{Name: "api.example.com", Type: "A", Value: "93.184.216.34", TTL: 300},
			{Name: "api.example.com", Type: "A", Value: "93.184.216.36", TTL: 300},
		},
		Elapsed: 23 * time.Millisecond,
	}
	fmt.Print(Dig(ans))

	fmt.Println(strings.Repeat("-", 40))

	missing := Answer{QName: "ghost.example.com", QType: "A", Status: "NXDOMAIN", Elapsed: 8 * time.Millisecond}
	fmt.Print(Dig(missing))
}
```

<UnderTheHood title="What a real resolver adds — and where Go's stdlib already does this for you">

Your resolver is the real machinery, simplified in two honest ways:

1. **The wire format.** Real DNS is a binary protocol over UDP port 53 (falling back to TCP for large answers, and the wire format is what `golang.org/x/net/dns/dnsmessage` packs and parses). A query and answer are packed structs with a header, question, and resource-record sections — not Go structs in memory. The *logic* you built (records, zones, the chain, the cache, CNAME following) is identical; only the transport differs.

2. **Recursion vs. delegation.** A real recursive resolver sends actual queries to the root, TLD, and authoritative servers, following **NS** (nameserver) referrals at each hop. We modeled that with the in-memory `zoneFor` delegation in Stage 2 — same shape, no network.

For everyday Go code you rarely write any of this: `net.LookupHost`, `net.LookupCNAME`, `net.LookupMX`, and `net.Resolver` (with a custom `Dial` if you need a specific server) call the OS resolver or a server you point them at. Reach for `golang.org/x/net/dns/dnsmessage` only when you need to build or inspect packets directly — a custom resolver, a DNS server, or a network tool. Now that you've built the model by hand, those stdlib calls are no longer magic: you know exactly what `net.LookupHost` is doing under the covers.

```go
	c.entries[k(r.Name, r.Type)] = entry{record: r, expires: c.now().Add(time.Duration(r.TTL) * time.Second)}
}

func (c *Cache) PutMiss(name, qtype string, ttl int) {
	c.entries[k(name, qtype)] = entry{negative: true, expires: c.now().Add(time.Duration(ttl) * time.Second)}
}

// Get returns (record, found, negative). negative=true means a cached NXDOMAIN.
func (c *Cache) Get(name, qtype string) (Record, bool, bool) {
	e, ok := c.entries[k(name, qtype)]
	if !ok || !c.now().Before(e.expires) {
		delete(c.entries, k(name, qtype))
		return Record{}, false, false
	}
	return e.record, true, e.negative
}

func main() {
	clock := time.Now()
	c := NewCache(func() time.Time { return clock })

	c.PutMiss("ghost.example.com", "A", 30) // cache the NXDOMAIN for 30s

	if _, found, neg := c.Get("ghost.example.com", "A"); found && neg {
		fmt.Println("t+0s   cached NXDOMAIN — no chain walk needed")
	}
	clock = clock.Add(31 * time.Second)
	if _, found, _ := c.Get("ghost.example.com", "A"); !found {
		fmt.Println("t+31s  negative entry expired — re-resolve")
	}
}
```

Negative caching uses the same expiry machinery; the `negative` flag distinguishes a cached failure from a cached answer. Negative TTLs are kept short so a name that *starts* existing is picked up quickly.

</Solution>

</Exercise>

<Exercise n={3} title="Round-robin A records" level="medium">

When a name has several A records (load balancing), resolvers rotate which one comes first on each query. Write `RoundRobin(recs []Record) []Record` that rotates the slice by one position each call (use a package-level counter), so successive queries return a different head. Show three calls cycling the head.

<Solution>

```go
package main

import "fmt"

type Record struct{ Name, Type, Value string }

var rrCounter int

// RoundRobin returns a rotated copy of recs, advancing the start each call.
func RoundRobin(recs []Record) []Record {
	if len(recs) == 0 {
		return recs
	}
	n := len(recs)
	out := make([]Record, n)
	for i := 0; i < n; i++ {
		out[i] = recs[(i+rrCounter)%n]
	}
	rrCounter = (rrCounter + 1) % n
	return out
}

func main() {
	recs := []Record{
		{Value: "10.0.0.1"}, {Value: "10.0.0.2"}, {Value: "10.0.0.3"},
	}
	for call := 1; call <= 3; call++ {
		fmt.Printf("call %d head -> %s\n", call, RoundRobin(recs)[0].Value)
	}
}
```

Rotating the order spreads load across the addresses. Real resolvers do this so a name with three A records sends roughly a third of clients to each — DNS as a poor man's load balancer. (Note the package-level counter is not goroutine-safe; a production version would guard it with an atomic or a mutex.)

<Exercise n={4} title="Resolve with cache + chain" level="hard">

Wire Stage 2's resolver to Stage 3's cache: a `ResolveCached(name, qtype string)` that checks the cache first (HIT → return, MISS → resolve from the zone, then `Put` the result) and reports which path it took. Demonstrate a miss-then-hit on the same name.

<Solution>

```go
package main

import (
	"fmt"
	"time"
)

type Record struct {
	Name, Type, Value string
	TTL               int
}

type entry struct {
	rec     Record
	expires time.Time
}

type Resolver struct {
	now   func() time.Time
	zone  map[string][]Record
	cache map[string]entry
}

func NewResolver(now func() time.Time) *Resolver {
	return &Resolver{now: now, zone: map[string][]Record{}, cache: map[string]entry{}}
}

func (r *Resolver) Add(rec Record) { r.zone[rec.Name] = append(r.zone[rec.Name], rec) }

func (r *Resolver) ResolveCached(name, qtype string) (Record, string) {
	key := name + "|" + qtype
	if e, ok := r.cache[key]; ok && r.now().Before(e.expires) {
		return e.rec, "HIT"
	}
	for _, rec := range r.zone[name] {
		if rec.Type == qtype {
			r.cache[key] = entry{rec: rec, expires: r.now().Add(time.Duration(rec.TTL) * time.Second)}
			return rec, "MISS (resolved + cached)"
		}
	}
	return Record{}, "NXDOMAIN"
}

func main() {
	clock := time.Now()
	res := NewResolver(func() time.Time { return clock })
	res.Add(Record{Name: "api.example.com", Type: "A", Value: "93.184.216.34", TTL: 300})

	rec, path := res.ResolveCached("api.example.com", "A")
	fmt.Printf("1st: %s via %s\n", rec.Value, path)

	clock = clock.Add(5 * time.Second) // still within TTL
	rec, path = res.ResolveCached("api.example.com", "A")
	fmt.Printf("2nd: %s via %s\n", rec.Value, path)
}
```

The first call misses, resolves from the zone, and caches the result with its TTL; the second call (within the TTL) hits the cache and skips the zone entirely. This is the whole resolver in one method.

</Solution>

</Exercise>

<Exercise n={5} title="Reverse lookup (PTR)" level="medium">

A **PTR** record maps an IP back to a name (reverse DNS). Build a `ReverseZone` with `AddPTR(ip, name string)` and `Reverse(ip string) (string, bool)`. Demonstrate resolving `93.184.216.34` back to `api.example.com`, and a miss for an unknown IP.

```go
package main

import "fmt"

// ReverseZone maps IPs to names — the PTR (reverse DNS) direction.
type ReverseZone struct{ ptr map[string]string }

func NewReverseZone() *ReverseZone { return &ReverseZone{ptr: map[string]string{}} }

func (z *ReverseZone) AddPTR(ip, name string) { z.ptr[ip] = name }

func (z *ReverseZone) Reverse(ip string) (string, bool) {
	name, ok := z.ptr[ip]
	return name, ok
}

func main() {
	z := NewReverseZone()
	z.AddPTR("93.184.216.34", "api.example.com")

	if name, ok := z.Reverse("93.184.216.34"); ok {
		fmt.Printf("93.184.216.34 -> %s\n", name)
	}
	if _, ok := z.Reverse("10.0.0.99"); !ok {
		fmt.Println("10.0.0.99 -> no PTR record")
	}
}
```

Reverse DNS is just a second index in the other direction. Real PTR records live in the special `in-addr.arpa` zone with the IP octets reversed, but the mapping is the same idea: IP → name.

<Recap>

- **The lookup chain** finds an answer no single server holds: root → TLD → authoritative, each hop a referral one level closer. Once found, the answer is cached for its TTL.
- **Records & the zone** (Stage 1): a `Record` is name + type + value + TTL; a `Zone` is a `map[string][]Record` answering lookups by name *and* type, because one name carries many records.
- **The resolver** (Stage 2) picks the most specific zone that owns a name (delegation), then looks the record up there — distinguishing "no zone" from NXDOMAIN, exactly as real DNS does.
- **The TTL cache** (Stage 3) skips the whole chain on a hit and treats `now >= expires` as a miss. Inject the clock as `func() time.Time` and you can fast-forward through expiry in tests instead of sleeping. A cache that ignores TTL serves dead addresses after a failover.
- **CNAMEs & cycle detection** (Stage 4): follow aliases until you reach an address, guarded by a **visited-set** (catches loops instantly) and a depth cap (backstops abusive chains). `a → b → a` returns a cycle error, not a crash.
- **Zone transfer** (Stage 5) dumps every record in a **stable order** (name, type, value) so primary and secondary nameservers can diff and sync — Go map iteration is randomized, so you *must* sort.
- **dig-style output** (Stage 6) formats results like the tool engineers actually read: header, question, answer sections in zone-file form.
- **Real DNS** adds the binary wire format over UDP/53 and network recursion — but the logic is what you built. For everyday Go, `net.LookupHost`/`net.Resolver` do it for you; reach for `golang.org/x/net/dns/dnsmessage` only when you build packets directly. You now know exactly what those calls do under the hood.
